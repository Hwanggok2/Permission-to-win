# 그래픽 리뉴얼 QA 준비

**이전 시안 보존 안내:** 최신 사용자 지시로 이 Tabletop 시안은 폐기됐다. 아래 기능/시각/빌드 검증은 이전 버전 증거이며 새 ‘한 수 진급’ UI의 최종 합격으로 사용하지 않는다. QA-013 후보는 시안 폐기로 후속 판정을 중단하고 미확정 상태를 보존한다. 신규 계획은 [RANK-UI-RESULTS.md](RANK-UI-RESULTS.md)를 따른다.

기준일: 2026-10-14 KST. **독립 영향32묶음 확인(31개 통과 후 낡은 기대값1개 갱신·별도1/1), Client Unity59/59·별도 Editor1/1, 최종 빌드/브라우저 연결 완료. QA-011/012 종결.** 다만 최종 브라우저 영어320 도움말 이미지에도 닫기 표시 누락을 관찰해 CAP-01을 **QA-013 표시 결함 후보**로 등록했다. 원인/실제 클릭 재확인이 필요하며 전체 시각 판정은 미마감이다. 아래 준비/중간 기록은 이력을 보존하며 최신 절을 따른다. 기존 기능 검증과 새 그래픽의 시각적 수용 여부는 구분한다.

## 이번 변경 범위

밝은 크림 배경과 청록 보드, 민트 고리/산호 마름모 말, 통일된9-slice 패널·버튼·아이콘, 모달의 그래픽 통일을 확인한다. Excel137문구·AI·광고 NoFill·진행 저장은 보존하며 레이아웃 보존 원칙에는 아래 사용자 추가 지시에 따른 결과 화면 변경만 예외를 둔다. QA 쓰기는 Docs/QA/와 Tests/만, Unity/빌드는 Client, 실제 브라우저 입력은 총괄 담당이다. 연결 Android 기기0개 상태이며 휴대폰 검증은 사용자 그래픽 수정 지시에 따라 보류된 상태로 기록한다.

총괄이 전달한 사용자 추가 지시: **큰 결과 패널을 제거하고 보드를 노출하며 승리/패배/무승부/마지막30에서 Retry·Lobby 정확히 두 버튼만 가로로 표시한다. Next와 결과 Close는 노출하지 않는다.** 양측 승리의 마지막 말을 약400ms 동안1.45→1.0배로 놓은 뒤 승리 줄을 약500ms 관찰하고, 이후 광고 기회 처리와 결과 버튼으로 이어진다. resolving부터 result까지 보드·힌트·일시정지 입력을 막는다. 승리 해금은 유지하고 로비 복귀 시 다음 해금 단계가 선택된다. 이전 승리 Next 강조 요구는 의도적으로 폐기됐으므로 새 구현의 회귀 결함으로 분류하지 않는다.

## 중간 캡처 읽기 — QA-011/012 열린 상태

총괄이 Client에 수정 요청한 두 문제를 QA가 저장된 PNG로 확인했다. [수정 전 캡처3개 및 해시](Evidence/qa-graphics-visual-findings-20261014/source-manifest.json)를 별도 보존했고 복사 중 변경은 없었다. QA가 Unity를 실행하거나 브라우저에서 재현한 결과는 아니다.

- **QA-011:** `animation-player-0.png`의 하단 네 번째 열 확대 민트 말 윗부분이 위 빈칸 원형에 가려진다. 총괄은 렌더 sibling 순서를 원인으로 보고했으며 Client가 마지막 말을 앞에 그리고 취소 시 원복하도록 수정할 예정이다. QA는 이미지상의 가림을 확인했으며 원인/수정 효과는 아직 독립 실행하지 않았다.
- **QA-012:** `map-ko-320-result-0/1.png`의 승리·패배 결과 상단에 일시정지 아이콘이 남아 있다. 총괄은 비활성 상태라고 보고했지만 정지 이미지로 입력 차단은 입증할 수 없다. 결과에서 숨기고 재시작 시 복원하는 수정이 예정돼 있다.
- 두 결과 캡처에서 큰 결과 패널 없이 보드가 보이고 Retry/Lobby가 가로로 배치된 것은 중간 구현으로 확인했다. 정확히 두 개만 조작 가능함·실제 클릭 동선·연출 시간·모든 결과/언어/해상도는 아직 통과 판정하지 않는다.

[이미지 관찰 기록](Evidence/qa-graphics-visual-findings-20261014/capture-review.json). 두 결함은 수정 완료와 동결 후 RES07/08 증거를 확인하기 전까지 열린 상태로 유지한다.

## 다음 실행 조건과 판정 제한

총괄/Client의 소스 동결 안내, 변경 파일 목록, 저장 자산/직렬화 참조, 결과 상태/연출/광고 순서 계약, native 검사 XML 및 한영320/390 화면과 양측 승리 연출 증거, 최종 빌드 정보가 다음 입력이다. 그때 기준선과의 차이를 먼저 읽고 필요한 독립 검사만 정한다. 새 그래픽·결과 연출 전체는 미판정이며 중간 이미지 결함2건은 열려 있다. 휴대폰 테스트를 시작하거나 Unity/브라우저를 대신 조작하지 않았다.
