# 광고 제거 패널·로비 아이콘 크기 독립 검토

2026-10-18 KST. 사용자 후속 요청은 작게 보이는 광고 제거 패널을 확대하고 상단 세 아이콘을 줄이는 것이다. 총괄이 구현·Unity 실행을 담당한다. 독립 검토자는 소스와 전달된 증거를 검토하고 이 문서만 수정한다.

## 원인과 수정 설계 검토

기존 `AdRemovalOfferLayout`은 패널 폭을 `Mathf.Min(350, css-24)`로 제한한다. 1080×1920/DPR3는 360 CSS px로 계산돼 적절하지만, native/Editor/DPR1의 1080px 폭은 350에 막혀 약 1/3 폭이 된다. 기존 검사는 화면 안에 들어가는지 확인했으므로 너무 작은 패널을 통과시킬 수 있었다.

- 실제 SafeArea의 portrait content 폭 약 92%를 기준으로 패널을 배치하는 방향에 동의한다. 전체 Screen 폭을 직접 사용해 중앙 게임 영역을 벗어나면 안 된다.
- 패널만 넓히지 않고 본문·제목·혜택 행·가격·상태·닫기·복원 영역도 함께 비례 확대한다. 제목의 X 예약폭, 복원 슬롯, 내부 간격처럼 고정값으로 남은 부분이 커진 글자를 자르지 않아야 한다.
- compact 판정과 총 높이는 확대 후 필요한 높이를 기준으로 한다. raw 높이만 검사하면 DPR1의 큰 글자/행이 호스트 안전영역을 초과할 수 있다.
- 320px 작은 화면은 44px 닫기와 48px 구매 입력을 유지하고 불필요한 여백·보조문구를 먼저 줄인다. 패널 폭 비율을 맞추려고 모든 행동을 작게 축소하지 않는다.
- 로비 세 아이콘은 그림 Rect를 약 30% 줄이고 110×110 기준 입력 영역은 유지한다. 물음표는 스프라이트 내부 glyph 폭이 좁으므로 최종 작은 화면에서 여전히 알아볼 수 있어야 한다. 대비를 개선한 크림 외곽선도 유지한다.

## 필요한 회귀

| 검사 | 기대 결과 |
| --- | --- |
| 1080×1920 DPR1, 720×1280 DPR1 | 약 1/3 폭 문제 재현 후 수정본에서 게임 내용 폭 약 92% 사용 |
| 1080×1920 DPR3, 390×844, 320×568 | 과대 확대 없이 폭 비율·본문 가독성·닫기/구매 유지 |

## 최종 구현 검토

`AdRemovalOfferLayout.cs`에서 실제 portrait content 폭을 사용해 `Min(css × 0.92, css − 24)`로 패널 폭을 계산하고, 350 기준보다 넓을 때 글자·혜택 행·X·하단 행동과 여백을 함께 확대하는 것을 확인했다. compact 판정은 확대 후 가용 높이에 따른다. 따라서 native1080/DPR1의 폭만 커지고 글자가 작은 채 남는 문제도 피한다. 320px 화면은 축소율을 적용하지 않아 기존 최소 행동 크기를 유지한다.

`LobbyStyleBuilder.cs`의 그림 Rect는 Help 64, 광고 제거 56, Settings 46으로 줄었다. 버튼의 기준 110×110 입력 영역은 유지되고, Help/Settings의 크림 Outline은 1.5로 얇아졌다. 프리팹 제작 코드 변경이며 런타임 UI 트리 생성은 추가되지 않았다.

Ready 캡처의 가격은 검사 어댑터가 제공한 예시다. 실제 판매 가격 확정 또는 결제 연결 증거로 해석하지 않는다. X에 보이는 옅은 면은 포커스 표시이며 테두리가 추가된 것은 아니다.

## 실행 결과 확인과 범위

총괄이 실행한 `Client/Evidence/lobby-scale-20261018/unity-tests.xml`을 직접 읽어 **6/6 Passed, 실패0, 건너뜀0**을 확인했다. 자동 검사는 한영·기존 5개 화면 유형과 native1080/DPR1·720/DPR1을 포함한다. `AssertOfferFits`는 화면 내부 여부 외 패널 폭 비율 86~94%, 텍스트 높이, 닫기/복원 최소44px 및 구매 최소48px, 입력 관통 방지를 검사한다. 직접 열기·재열기·구매 대기·보유 권한·미지원 안내 관련 회귀도 이 6개 검사에 포함된다.

총괄은 WebGL 빌드 오류/경고0, 로컬 브라우저에서 X/외부 터치 닫기·재열기, 오류 로그 없음도 보고했다. 독립 검토자는 그 입력을 직접 실행하지 않았으며 로컬 WebGL PNG 2개를 시각 확인했다. 공개 링크는 푸시 전이므로 이번 기록은 공개 배포 완료 증거가 아니다. 실제 광고/IAP 실행 또한 검토 범위가 아니다.

## 결론

요청한 패널 확대와 상단 아이콘 축소가 확인됐다. 이번에 직접 확인한 소스·XML·13개 PNG( Unity 11개, WebGL 2개)에서 추가 수정이 필요한 차단 문제는 발견하지 못했다.
