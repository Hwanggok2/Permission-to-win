## 새 빌드 확인 순서

1. 로비·도움말·설정·고지의 일관된 패널/버튼/아이콘과 한국어/영어를 확인한다.
2. 밝은 바탕과 청록 보드, 움푹한 빈칸, 민트 고리/산호 마름모를 실제 대국에서 확인한다.
3. 플레이어와 AI의 마지막 승부수 연출을 확인한다. 자동 연출 검사와 실제 관찰 범위를 구분한다.
4. 결과에서 보드/승리 줄이 가려지지 않고 재도전/로비 두 버튼만 가로로 보이는지, 재도전·해금·로비 다음 단계 선택이 동작하는지 확인한다.
5. 320×568 최소 모의 조건과 390×844에서 겹침·잘림·입력 및 브라우저 오류를 확인한다.
6. 새 APK/WebGL 해시와 검사 증거를 연결한다. 실제 기기가 준비되면 설치·실행·터치·복귀·저장을 별도 확인한다.

ADB를 시작한 뒤 연결 목록은 0개였다. 휴대폰 시험은 미실행이다. 사용자에게 연결을 안내한 뒤 그래픽 보완 우선 지시를 받았다. 데스크톱의 휴대폰 크기 화면을 실기기 통과로 기록하지 않는다. 실제 토스 SDK·광고·결제·구매 서버 시험은 별도다.
