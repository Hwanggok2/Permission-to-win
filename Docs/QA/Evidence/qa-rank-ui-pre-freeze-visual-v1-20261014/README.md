# Rank UI 동결 전 초기 캡처 관찰

2026-10-14. Client 생성 PNG3개를 수정 전 이력으로 복사하고 해시를 [manifest](source-manifest.json)에 보존했다. 복사 전/후 원본과 사본 해시는 일치했다. QA는 **보존한 사본3개를 직접 읽었고** Unity/브라우저/실기기를 실행하지 않았다. Client가 아직 컴파일/저장 수정 중인 버전이며 최종 동결 소스·빌드와 연결하지 않는다.

| 캡처 | QA 관찰 | 수정 후 확인 |
| --- | --- | --- |
| [ko-390-lobby](ko-390-lobby.png) | 제목/멀티/도움말/설정은 보이나 카드 영역이 비어 있고 단계 카드가 없다. | 기본 스크롤에서 첫 행2카드가 보임.30단계까지 스크롤하고 각 선택/잠금/상세 진입이 맞는지 확인. |
| [en-320-lobby-middle](en-320-lobby-middle.png) | 제목 아래 큰 빈 영역을 지나 Stage01/02가 표시되고 다음 행은 하단 버튼 근처에서 잘린다. 캡처만으로 실제 정규화 스크롤 값은 확인할 수 없다. | 콘텐츠 기준점과 카드 배치를 수정한 후 상단/중간/끝 화면, 과도한 빈 영역·하단 고정 버튼 침범, preview 닫기 후 스크롤 보존을 확인. |
| [ko-320-win](ko-320-win.png) | 보드 내부의 여러 세로 격자선 등이 보이지 않아7×6 배치를 식별하기 어렵다. | 상세/대국/결과320·390에서 모든 격자선의 연속성과 흑백 돌/preview/승리선 식별성을 확인. |

총괄이 Client에 전달한 원인 후보는 Content의 top anchor와 자식 center anchor 불일치,1.8논리픽셀 격자선이 축소되어 생긴 raster 누락이다. 이는 **총괄의 가설이며 QA가 원인을 확정한 결과가 아니다**. 상단 기준 카드·3이상 논리픽셀 격자선 수정 요청이 전달됐지만, 수정 완료/재검증 통과는 아직 보고하지 않는다.

대상은 RUI01/02/03/14. 동결 전 예비 관찰로 관리하며 새 제품의 최종 합격/공식 런타임 실패 건수에 합산하지 않는다. 수정된 native 캡처와 동결 소스/빌드가 나온 후 총괄의 실제 포인터 확인까지 연결해야 한다.
