## 연출과 수정 근거

- Unity 실제 코루틴 검사에서 합법 국면을 주입하고 플레이어 버튼/AI 탐색을 통해 각각 마지막 수를 진행했다. 1.45배→약0.4초 후1배→약0.9초 뒤 광고 요청/결과 버튼 순서는 `Client/Evidence/graphics-refresh-20261014/animation-timeline.csv`에 기록됐다. 이는 전 단계 사람 플레이나 실제 광고 SDK 시험이 아니다.
- 중간 캡처에서 확대 말이 위행 빈칸 뒤에 가리는 것을 발견했다. 연출 중 해당 말을 앞으로 그리고 완료/취소 때 원래 순서·크기로 복원하도록 고쳤다. 결과의 남은 일시정지 버튼도 숨기고 재시작 때 복원했다.
- 최종 수정 후 Unity 전체59/59 통과. 이후 **에디터의 미저장 씬 보호 조건만 보완**해 별도1/1 검사를 통과했다. 두 실행을 하나의60개 실행으로 합산하지 않는다. 게임 런타임·아트·프리팹·배포 빌드는 보호 조건 추가 전후 동일하다.
- 브라우저 정지 캡처만으로 0.4초의 모든 프레임을 검증했다고 주장하지 않는다. 실제 입력의 승패 전환/최종 화면은 위 브라우저 기록, 양측 연출의 시간·확대·복원·입력 잠금·광고 순서는 Unity 타임라인과 검사로 구분한다.
