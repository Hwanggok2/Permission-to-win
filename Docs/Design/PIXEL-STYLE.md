# 캐릭터 도트 스타일 기준

2026-10-15. 후반 인물 C05~C19의 v5 교체에서 빠졌던 초반 C02~C04도 v6로 다시 제작했다. 현재 C02~C19의 18명·54상태에 최초 훈련병의 굵은 도트 기준을 적용했으며, 훈련병과 결승 복장 변형은 유지했다. 최신 선택본은 [v6 목록](assets/characters-pixel-20261015-v6/manifest.json), 적용 결과는 [Unity 검증](../../Client/Evidence/pixel-complete-20261015/verification.json)이다.

제작할 때마다 [최초 훈련병 원본](../../Client/Assets/StageGame/Art/PixelMilitary/C01.png)을 스타일 참조로 직접 넣는다. 직전 생성물은 인물의 얼굴·자세·복식 참고로만 쓴다. 이전 생성물만 연쇄 참조하면서 그림체가 점차 매끈해지는 것을 피한다.

- 얼굴, 모자, 손, 군복 모두 눈에 보이는 계단형 윤곽을 쓴다. 1536×1024 아틀라스에서 주요 도트 덩어리는 약 8px, 검정 외곽선은 1~2 논리 픽셀을 기준으로 한다. 이는 생성·시각 검토 기준이며 모든 출력이 정확한 192×128 정수 격자라는 보장은 아니다.
- 피부는 약 3단계, 군복은 약 4단계의 평평한 명암을 목표로 한다. 둥근 벡터 곡선, 흐린 윤곽, 부드러운 얼굴 그라데이션, 세밀한 머리카락·천 질감은 넣지 않는다.
- 둥근 체형이나 코는 개성으로 유지하되 그 외곽은 도트 계단으로 그린다. 모든 캐릭터를 같은 각진 얼굴로 바꾸지 않는다.
- 작은 계급장·태극기는 식별 가능한 세부 도트를 허용한다. 개수와 배치가 틀리면 사용자가 승인한 직접 픽셀 편집으로 교정한다. 얼굴·자세·원본 알파는 해당 교정에서 보존한다.
- 3개의 512px 셀, 시작·고민·패배 순서, 몸과 손의 셀 내부 배치, 투명 배경을 지킨다. 훈련병은 계급장 없음. 계급별 개수·견장 경사·지휘 띠·머리 길이는 [캐릭터 기준](CHARACTERS.md)을 함께 따른다. 가려진 팔·견장 위에 표식을 억지로 덧그리지 않는다.
- 매번 전체 19명과 결승 복장 변형의 실제 테마 참조를 확인한다. 변경한 캐릭터 범위만 검사하거나, 이미지 생성 완료를 게임 적용 완료로 간주하지 않는다.
- 전체 아틀라스, 확대 표식, 실제 1080/390 게임 화면을 비교한다. 파일 생성이나 자동 검사만으로 그림체 검토를 대신하지 않는다.
- Unity 캐릭터 임포트는 Point, mipmap 끔, 무압축을 사용한다. 플랫폼별 압축 재활성화는 실제 기기에서 윤곽·색상·메모리를 함께 검토한 뒤 결정한다. 이번 작업에는 새 모바일/WebGL 빌드·기기 메모리 측정이 포함되지 않았다.

내장 ImageGen의 [최종 프롬프트 15개](assets/characters-pixel-20261015-v5/prompts.json)와 생성 원본을 보존했다. [직접 교정 기록](assets/characters-pixel-20261015-v5/manual-corrections.json)은 C08 한 견장의 3개 V, C13 노출된 네 견장의 3개 마름모, C16 여섯 견장의 3개 무궁화에 대한 좌표·해시를 기록한다. 실제 게임 연결은 저장된 RankTheme와 프리팹으로 유지한다.

초반 3명의 [v6 프롬프트](assets/characters-pixel-20261015-v6/prompts.json)와 [C02 패배 표식 교정](assets/characters-pixel-20261015-v6/manual-corrections.json)을 추가 보존했다. C02 가슴의 추가 막대만 주변 주머니 색으로 지워 한 줄로 맞췄으며, 허용 영역 밖 픽셀과 전체 알파가 동일함을 검사했다. [수정 전후 비교](../../Client/Evidence/pixel-complete-20261015/style-comparison.png).
