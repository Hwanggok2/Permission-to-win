# 4목 — 부대 대국과 사단 대회 이야기

**현재 적용 상태(2026-10-15):** 사용자 범위 승인 후 아래 24+6 배치와 이름·한영 대사·캐릭터 그림을 Excel/게임에 연결했다. Unity 82/82와 데이터 45/45 통과. [최종 통합 기록](PIXEL-INTEGRATION.md), [데이터 계약](../../GameData/TOURNAMENT-CONTRACT.md). 아래 제작 순서와 적용 대기 설명은 초기 기획 이력이다.

2026-10-15 (KST). **사용자 선택: 부대 대국24단계 + 대회6단계 = 총30단계.** 계급뿐 아니라 보직·군종으로 상대를 구분하고, 패배한 AI가 사단 대회를 소개한다. 구체적인 인명·성격·재등장 순서는 아래 제작안이다. 기획 반영과 Excel·Client·이미지 적용 상태를 구분한다. 개발 표시명은4목 / Four in a Row이며 상점 브랜드는 미확정이다.

## 이야기의 중심

사회에서4목 프로였던 플레이어가 입대한다. 훈련병 동기 **강민재**는 프로라는 소문을 듣고 먼저 도전한다. 훈련 수료와 부대 생활을 거치며 병사, 간부, 교류 행사에 온 공군 중사, 지휘관들까지 대국을 청한다. 플레이어는 계급보다 각자의 생각하는 방식과 승부에 임하는 태도를 알아간다.

사단장과의 마지막 대국에서 승리하면, 패배한 사단장이 **사단 병사부4목 대회**를 알려 준다. 대회의 상대는 모두 이병·일병·상병·병장이다. 계급이 낮아도 게임 실력은 높을 수 있음을 보여 주고, 결승에서는 꾸준히 연습해 온 첫 동기와 재회한다. 초반의 ‘프로인지 확인하겠다’는 도발은 마지막에 서로의 실력을 인정하는 말로 바뀐다.

플레이어는 처음에 훈련병이며 훈련 수료라는 시간 경과 후 이병이 된다. **대국 승리가 군 진급의 원인이 아니다.** 강민재도 대회 때는 이병이다. 대국은 자발적인 취미·교류 활동이며 패배에 군 생활상의 처벌을 연결하지 않는다. 실존 부대·인물·공식 대회 재현을 목표로 하지 않는 가상의 이야기다.

## 30단계 배치

## 전환과 재도전

- **01 시작:** “이 게임의 프로라고 했지? 그런데 내가 이길 것 같아.”를 유지한다. 훈련병의 군모 없는 짧게 민 머리·긴소매 군복·지정 세 자세는 기존 시안 검토와 연결한다.
- **02 진입:** 단계 설명으로 훈련 수료 후 부대 생활임을 알린다. 승리로 진급했다는 결과 연출은 만들지 않는다.
- **24 플레이어 승리:** 사단장의 AI 패배 대사 “내가 졌군. 사단 병사 대회에서도 실력을 보여 주게.” 뒤 다음 행동이 **‘64강으로’** 연결된다. 23승리나24패배·무승부에는 대회 초대를 먼저 출력하지 않는다.
- **25–29 승리:** 다음 라운드로 진행한다. 패배·무승부는 같은 상대·라운드 재도전이다. 64강부터 다시 시작하거나 입장권·광고 시청을 요구하지 않는다.
- **30 승리:** 강민재가 “네가 챔피언이야. 다음에도 나랑 둬 줘.”라고 인정한다. 짧은 우승 결과와 재도전/로비 행동으로 끝낸다. 31단계·새 재화·추가 결제를 만들지 않는다.
- 재대결은 복습이다. 초대·우승 대사를 다시 봐도 완료·해금·광고 집계나 우승 기록을 중복 지급하지 않는다. 복귀·재시도에서도 현재 라운드를 보존한다.

## 표시와 대사

계급(rank), 보직(role), 군종(service)을 분리한다. 소대장·중대장·대대장·연대장·사단장은 보직이다. 큰 이름은 **‘중대장 장태오’**, 보조 정보는 **‘육군 · 대위’**처럼 표시한다. 공군 상대는 **‘공군 중사 한유진’**, 대회는 **‘64강’**과 **‘이병 문시온’**을 구분한다. 인물 문서의 보직·계급 배치는 가상의 개별 설정이며 실제 모든 부대의 편제표가 아니다.

이야기는 기존 AI 말풍선·카드 설명·결과 행동으로 전달하고 긴 스토리 모달은 추가하지 않는다. **aiWinKey=AI 승리/플레이어 패배**, **aiLoseKey=AI 패배/플레이어 승리**다. 이름·보직·군종·라운드·대사·버튼은 Excel Strings ko/en 키로 연결한다. 한국어 대사 초안은 창작 명세이며 별도 런타임 문자열 원본이 아니다.

재등장은 같은 인물 ID와 얼굴을 유지하고 대회용 대사·등장 시점의 계급을 적용한다. C01 기본 계급을 덮어써1단계까지 이병으로 바꾸지 않는다. 2단계씩 만나는 상대는 첫 승리에서 다음 인물·대회를 예고하지 않고 한 판 더 두는 대사를 쓴다.

## 적용과 검증 상태

읽기 확인한 최신 [데이터 설명](../../GameData/README.md)은 기존30단계·18개 표시·269개 한영 문자열이다. 이전 v9의237개·44개 검사와 최신 데이터의 기존 검사 결과는 **이번 서사 변경의 통과 증거가 아니다.** [총괄 계약](../Management/CONTRACT.md)과 데이터 형식의 이전 배분은 담당자가 이번24+6안으로 통합해야 한다. 이 역할은 Docs/Design만 수정하며 다른 역할을 재개하거나 메시지로 지시하지 않는다.

데이터 인계안은 기존30개 ID·시작판·합법성 근거를 보존하면서 인물·표시·대사를 새 배치로 연결하는 것이다. 마지막6개 시작판이 대회에 적절한지와 난이도는 별도 검증한다. 저장은 서사 버전을 구분하고 이전 완료 기록을 삭제하지 않는다. 과거25–30 클리어를 새 대회 우승으로 자동 간주하지 않는 이관 규칙과 기존 진행자의 대회 진입 조건은 총괄·Client가 구현 전에 정한다.

이미지는 **설정표 → 비교 시안 → 사용자 디자인 확정 → 상태별 이미지 → Excel/저장 프리팹 연결** 순서다. 기존 훈련병을 보존하고 다른18명·54상태를 신규 생성해 [이미지 목록](assets/characters-20261015-v1/README.md)에 저장했다. 추가 요청으로 C06~C18의13명·39상태 [군모 앞 표식 버전](assets/characters-caps-20261015-v2/README.md)도 생성했다. 전체 디자인의 사용자 최종 수용과 Excel/게임 연결은 미완료다. 사용자 승인 전 WebGL/Android 빌드·게임 브라우저 실행은 보류한다.

검수에서는30단계 중복/누락, 병사만 참가하는 대회,24승리에서만 초대,30 이후 다음 단계 없음, 한영 인물·군종·보직·얼굴·대사 일치를 확인한다. 현재는 기획 문서와 캐릭터 이미지 생성까지 반영했으며 재미·몰입·실제 플레이·실기기 가독성은 미검증이다.
