# 픽셀 게임판·캐릭터 적용

2026-10-15. 사용자 요청: 기존 픽셀 캐릭터와 어울리게 게임판을 리디자인하고 디자인을 실제 게임에 적용한다.

## 최신 초반 캐릭터 도트·전체 연결 확인 — 2026-10-15 (v6)

이전 교체 범위가 C05~C19여서 초반 문시온·오준호·정한결은 v4 이미지로 남아 있었다. C02~C04의 시작·고민·패배 9상태를 기존 훈련병의 굵은 계단형 도트로 다시 제작해 적용했다. 오준호의 짧은 머리, 넓은 웃음과 손짓 등 개성은 유지했다. 이병 패배 그림에 생성된 추가 계급장 막대는 사용자 승인 범위의 직접 픽셀 교정으로 제거했다.

현재 선택은 C01·결승 복장 v4, C02~C04 v6, C05~C19 v5다. [v6 목록](assets/characters-pixel-20261015-v6/manifest.json)에 전체 20장·60상태를 기록했다. 전체 원본/복사본 해시, 실제 RankTheme의 GUID·표정 참조 60개, Point/mipmap 끔/무압축 설정을 검사했다. 앞으로 특정 계급 범위에 한정하지 않고 전체 선택 파일을 확인하도록 검사를 강화했다.

관련 Unity 검사 **3/3 통과**, 19명·결승 복장과 오준호 대회 재등장의 표정별 게임 캡처 **69장 검토**를 완료했다. 오준호는 부대 3단계와 대회 32강에서 390/1080 너비 모두 수정본으로 확인했다. [검증 기록](../../Client/Evidence/pixel-complete-20261015/verification.json), [실제 참조 대조](../../Client/Evidence/pixel-complete-20261015/runtime-reference-audit.json), [오준호 게임 화면](../../Client/Evidence/pixel-complete-20261015/oh-junho-in-game.png), [수정 전후 비교](../../Client/Evidence/pixel-complete-20261015/style-comparison.png).

Unity 프로젝트 적용 완료이며 기존 APK/WebGL 산출물은 다시 빌드하지 않았다. 이전 전체 87개 검사, 실제 기기·사람 플레이 검증과 이번 이미지 관련 검사는 구분한다. 원본·이전 버전과 v5 검증 이력을 보존했다.

## 이전 도트 스타일·계급장 교정 — 2026-10-15 (v5)

병장부터 후반 간부·대회 일병까지15명·45상태를 최초 훈련병 원본과 같은 굵은 도트 윤곽으로 다시 제작했다. 얼굴·모자·손의 매끈한 곡선과 가는 선을 계단형 픽셀 표현으로 바꾸고 각 인물의 표정과 개성을 유지했다. 전체20장·60상태의 현재 선택본은 [v5 목록](assets/characters-pixel-20261015-v5/manifest.json), 내장 ImageGen의 입력·프롬프트와 후속 제작 기준은 [도트 스타일](PIXEL-STYLE.md)에 기록했다.

사용자가 직접 픽셀 수정을 승인했다. C13 노출 견장 네 곳의 마름모를3개, C16 견장 여섯 곳의 무궁화를3개, C08 고민 자세 한 견장의 V를3개로 교정했다. 표식 주변의 지정 영역 외 RGB와 전체 알파가 생성 원본과 동일함을 검사했다. 이전 버전20장은 변경하지 않았다.

캐릭터 임포트는 Point 필터·mipmap 끔·무압축으로 저장했다. 저장된 테마·프리팹 연결,30단계의 인물과 표정 전환, 대표7명의1080/390 화면28장을 확인했으며 관련 Unity 검사 **3/3 통과**다. [검증·소스 동결](../../Client/Evidence/insignia-pixels-20261015/verification.json), [수정 전후 비교](../../Client/Evidence/insignia-pixels-20261015/style-comparison.png), [게임 내 표정 비교](../../Client/Evidence/insignia-pixels-20261015/unity-portrait-contact.png). 이번에는 전체87개나 Android/WebGL 빌드·실제 기기 검사를 다시 실행하지 않았다.

## 직전 캐릭터·초기 대국 수정 — 2026-10-15

19명·결승 이병 복장 변형1종의20장·60상태를 저장된 테마와 프리팹에 적용했다. C01 원본은 보존하고 훈련병은 계급장 없이, 결승 이병은 가슴1줄로 분리했다. 각 인물의 얼굴·체형·표정·손짓을 구별하고, 병사 머리 길이를 훈련병→이병→일병→상병→병장 순으로 조금씩 길게 맞췄다. C19 일병의 긴 앞머리를 없앴다. 오른쪽 위팔 태극기, 병사 가슴 주머니 계급장, 간부의 옆으로 누운 견장대와 지휘 띠를 반영했다. 세부 기준·출처는 [캐릭터 문서](CHARACTERS.md), 선택된 내장ImageGen 출력과 프롬프트는 [v4 manifest](assets/characters-uniform-20261015-v4/manifest.json)에 기록한다.

대국은24/30단계가 빈 판,8단계가 AI 선공이다. 한 수로 끝나는 초기 배치를 exporter에서 거절하고, AI의 첫5번 착수에는 임의 실수 선택을 끄고 짧은 위협을 더 읽는다. 자세한 기본 난이도·보호 구간·재시작 처리는 [난이도 계약](../../GameData/DIFFICULTY-CONTRACT.md)을 따른다. 초기 배치와 선공을 보존한다는 아래 이전 기록은 이번 추가 요청으로 대체됐다.

Unity 전체87/87·데이터45/45와 한영320/390/1080 화면 검증을 완료했다. [최신 검증·소스 동결](../../Client/Evidence/opening-ranks-20261015/verification.json), [일병 적용 화면](../../Client/Evidence/opening-ranks-20261015/screens/ko-stage-29.png), [병장 적용 화면](../../Client/Evidence/opening-ranks-20261015/screens/ko-stage-5.png). 원본 이미지는 덮어쓰지 않았다. 새 Android/WebGL 빌드나 실제 기기·사람 밸런스 검사는 포함하지 않는다.

당시 남았던 C13·C16의 표식 누락은 위 v5의 직접 픽셀 교정으로 처리했다. 당시 자동 테스트 통과와 그림 오류의 시각 검토는 별도 증거로 유지한다.

## 최신 대국 헤더 수정 — 2026-10-15

사용자 스크린샷 피드백에 따라 제목 배경을 숨기고 글자를 30% 키워 조금 위로 이동했다. 일시정지 버튼과 제목 영역의 높이를 맞추고, 계급·이름·난이도 패널 높이를 20% 줄여 제목 행과 말풍선 사이의 겹침을 없앴다. 한영 320/390/1080 화면과 관련 Unity 검사 **4/4 통과**를 확인했다. 이번에는 전체 82개를 재실행하지 않았다. [현재 화면](../../Client/Evidence/pixel-header-20261015/screens/ko-1080-plain-match.png), [현재 검증·소스 해시](../../Client/Evidence/pixel-header-20261015/verification.json)를 따른다. 아래 82/82·45/45는 직전 통합 검증 기록이다.

## 제작 결과

- [새 목재 보드](assets/board-pixel-20261015-v1/WoodenBoard.png): 굵은 어두운 목재 테두리, 밝은 갈색 상판, 제한된 나뭇결. 7×6 격자·돌·입력 영역은 기존 게임 객체로 표시한다. [내장 ImageGen 프롬프트·생성 기록](assets/board-pixel-20261015-v1/generation.json).
- 훈련병 v12와 [기본 인물18명](assets/characters-20261015-v1/README.md), [군모 변형13명 최신 목록](assets/characters-caps-20261015-v2/README.md)을 사용한다. C06~C18은 군모 버전, 나머지는 기본 버전이다. C06은 세 자세의 표식을 아래 방향 V로 고친 [v2 수정본](assets/characters-caps-20261015-v2/C06-choi-geonwoo-cap-v2.png)을 쓴다. C07~C18은 v1 그대로다.
- 각 인물의 시작·대국 중·AI 패배3상태를 직렬화된 Sprite로 연결한다. 플레이어 승리 때만 AI 패배 그림을 쓴다. AI 승리·무승부에는 대국 그림을 쓰고 재도전하면 시작 그림으로 복원한다.
- 수용된 내무반 v20 배경을 전체 화면 뒤에 두고 입력을 가로채지 않게 한다. 이름·말풍선 배경은 알파0.68이며 글자는 불투명하다. 최신 대국 제목은 배경 없이 글자만 표시한다.
- 기존 저장 프리팹에 목재 보드·픽셀 흑백 돌·올리브 버튼을 연결하는 에디터 적용 도구를 준비했다. 런타임 UI 트리 조립은 추가하지 않는다.

## 데이터 연결안과 검사

사용자가 선택한 부대24단계와 병사 대회6단계를 반영했다. 01~12는C01~C12, 13~24는C13~C18을2단계씩 배치한다. 25~30은C02/C03/C04/C05/C19/C01이며64강/32강/16강/8강/4강/결승이다. 사단장의 대회 초대는24승리, 우승 문구는30승리에만 연결한다.

Excel Stages의CharacterId 열과 Strings의149개 한영 키를 추가하는 변경안을 준비했다. 기존269개 문구와30개 시작판·ID·chapter·starter·AI 설정·별점은 보존했다. 기존 셀 서식·고정창·입력 유효성도 비교했다. 총418개 문자열이며 exporter와Python 회귀검사45개가 통과했다. 기존 저장 구조는 유지하고 이전 클리어 기록을 삭제하지 않는다. 신규 우승 결과 문구는 실제30단계 승리 결과에서만 표시한다.

## 적용 상태

C06 방향 수정본은 Docs/Design에 저장하고 파일 크기·알파·해시와 세 자세의 방향을 확인했다. 사용자 범위 승인 후 PreparePixelArt.py가 최신 manifest의 v2를 선택하도록 바꿨고, Client에는 기존 C06.png를 보존하면서 C06-cap-v2.png로 추가했다. Sprite 영역을 다시 계산하고 저장된 테마는 v2를 참조한다.

이미지 생성·파일 복사·연결 코드와Excel 변경·데이터 검사, Unity 임포트·프리팹 저장·에디터 플레이/화면 회귀 검증을 완료했다. 최초 화면에서 인물과 말풍선 겹침을 발견해 말풍선을 오른쪽으로 옮겼고, 차례 안내는 저장 프리팹의 게임판 자식으로 배치해 작은 화면에서도 대사를 가리지 않게 했다. 기존 요청대로 차례 안내는 글자만 표시한다. 빈 별은 밝은 별도 스프라이트를 써 반 별을 구분하고, 도움말의 돌 그림도 새 테마와 일치시켰다.

최초 자동 승인 거절 사유는[루트 AGENTS.md](../../AGENTS.md)의 역할별 폴더 제한이었다. 이후 사용자가 “작업 범위를 확장하고 적용·검증 진행”으로 Client/GameData 수정과 Unity 적용·검증을 명시 승인했고 승인된 실행으로 프리팹 저장을 완료했다. WebGL/Android 새 빌드·브라우저 실행·출시는 수행하지 않았다.
