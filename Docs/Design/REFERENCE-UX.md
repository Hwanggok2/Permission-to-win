## 우리 게임에 확정한 적용

- **고유 표현 유지:** 짙은 배경, 민트/산호 돌, 둥근 자체 도형과 기존 Noto 폰트를 재사용한다. 완료·도전·잠금은 색과 기호/짧은 글자를 함께 사용한다. 실제 선택 표시는 **`[번호]` 괄호와 민트 배경 강조**이며 진행 상태 문구와 별도로 표현한다. 참고 게임의 학교 직책·이름·상품 장식을 가져오지 않는다.
- **단계 선택:** 1~10 입문, 11~20 전술, 21~30 도전의 3챕터를 이동하며 **5열×2행**의 10개 노드를 보여준다. 챕터명은 표시용 구분이지 검증된 난이도 등급이 아니다. 선택 단계 이름·진행 상태와 큰 시작 버튼을 가까이 둔다. 잠긴 단계는 살펴볼 수 있으나 시작은 막고 먼저 완료할 단계를 안내한다. 완료 단계는 재도전할 수 있다.
- **저장과 끝 처리:** 최고 완료 단계와 최고 해금 단계를 구분한다. 기존 저장의 완료 추론은 `해금 - 1`까지만 하며 30단계 해금만으로 완주를 표시하지 않는다. 30단계 완료 뒤 존재하지 않는 31단계로 이동시키지 않는다. 언어·효과음·광고 카운터·중복 결과 방지를 보존한다.
- **도움말과 결과:** 열 선택→아래 빈칸에 낙하, 가로/세로/대각선 4개 연결을 짧은 문구와 저장된 자체 도형으로 보여준다. 승리에서는 다음 단계, 패배·무승부에서는 재도전을 강조하고 로비 이동은 보조로 둔다. 최종 단계 완료는 단계 선택/재도전으로 이어진다. 기존 결과 광고 처리 경계를 유지한다.
- **기존 UI 계약 유지:** 화면·공통 버튼은 저장 프리팹과 직렬화 참조를 사용한다. 모든 새 사용자 문구는 Excel Strings의 한국어/영어로 관리한다. [HOST-UI.md](HOST-UI.md)의 OS/호스트 inset 아래 **추가 64 CSS px** 예약, CSS→렌더 좌표 변환, 전체 화면 배경, 44 CSS px 입력 검사를 유지한다. 64는 공식 토스 높이가 아닌 제품 시험 여백이며 Android 단독 앱에는 적용하지 않는다. 카드·캡션·고정 버튼·광고 예약 공간은 서로 겹치지 않아야 한다.
