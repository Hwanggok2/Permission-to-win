## 이미지 제작 명세

현재 검토 중인 [훈련병 v12 시안](../../Overview/assets/military-pixel-20261015/recruit-buzz-cut-atlas-v12.png)을 스타일 참고로 쓴다. **C01 훈련병의 군모 없는 짧게 민 머리와 긴소매 상의**는 유지한다. 2026-10-15 추가 요청으로 C06~C18 부사관·장교13명의 **군모 앞 표식 버전**을 별도로 생성했다. 각 인물의 기존 얼굴·세 자세와 모자 없는 원본을 보존하며 [군모 버전 이미지 목록](assets/characters-caps-20261015-v2/README.md)에서 비교한다. 이전 계급별 모자 원형 얼굴을 새 인물19명의 최종 아트로 간주하지 않는다. v12는 시안이며 전 캐릭터의 디자인이 승인된 상태가 아니다.

- **공통:** 거친 사각 픽셀 묶음, 굵은 계단형 외곽선, 제한된 색, 상반신과 같은 크기의 책상, 통일된 카메라·몸 비율·책상 기준선. 투명 배경으로 제작하고 말풍선·이름·계급 글자는 이미지에 굽지 않는다.
- **인물 구별:** 얼굴 윤곽·눈썹/눈·안경·자세 중 최소 두 가지로 구별한다. 모자나 색만 바꾼 동일 얼굴19종으로 만들지 않는다. 같은 인물은 모든 자세에서 얼굴·머리·체격을 유지한다.
- **군종:** 공군 중사를 조종사로 자동 설정하지 않는다. 군종·보직은 현지화된 UI 텍스트로 알린다. 실제 부대 문장·이름표·국기·로고·실존 인물 사진을 복제하지 않는다.
- **기본3상태:** 도전 시작 / 생각하는 대국 자세 / AI 패배. AI 승리는 대국 자세와 승리 대사를 우선 재사용한다. 첫 동기의 지정3자세는 보존하고 다른 인물은 성격에 맞게 손·어깨·시선을 달리한다.
- **대회 재등장:** C01~C05는 같은 얼굴을 쓴다. C01의 표시 계급은 이병이 되지만 머리·체형을 다른 사람처럼 바꾸지 않는다. 부대/대회의 감정 차이는 대사를 먼저 적용하고 추가 표정은 검토 후 결정한다.
- **제작량:** 기존 훈련병3상태를 보존하고 나머지18명×3=54상태를 신규 생성했다. 전체19명·57상태가 이미지로 존재하지만 사용자 최종 수용·Unity 적용은 미완료다. 새18개 파일은1536×1024 RGBA, 각512×1024 셀에 도전 시작/대국 중/AI 패배를 왼쪽부터 배치했다. 모든 시트의3자세·인물 특징을 이미지 출력으로 검토하고 크기/알파/원본 복사 일치를 확인했다. [프롬프트·개별 파일](assets/characters-20261015-v1/README.md), [출처 기록](../../Licence/CHARACTER-ART-20261015-V1.json).
- **군모 추가:** C06~C18의13개 PNG·39상태를 별도 버전으로 생성했다. C07은 회청색 군모, C14~C18은 정모, C17/C18은 각각 별1개/2개다. 앞 표식은 게임용 단순 도형이며 실제 군 표장 고증 완료를 뜻하지 않는다. 전부1536×1024 RGBA·3셀 구성이며 크기·알파·원본 보존·복사 일치를 확인했다. - **관리:** 인물ID/상태/리비전으로 파일을 구분하고 사용자 자산을 덮어쓰지 않는다. 기존 훈련병 원본·스케치·생성 기록은 읽기 전용 참고로 보존한다. 확정 후 픽셀 크기·알파·여백·책상 위치·잘림과 출처/해시를 대조해 Licence 대장에 실제 파일만 등록한다.

## Excel과 저장 프리팹 연결안

구현 필드 이름은 데이터·Client 계약에서 확정하되 다음 관계를 유지한다. 별도 런타임 대사 파일이나 코드 상수는 만들지 않는다.

| 정보 | 원본과 연결 기준 |
| --- | --- |
| 인물 | Excel의 안정적인 characterId를 이름·군종·계급·보직 키 및 초상 세트ID에 연결. C01~C19는 제안 ID다. |
| 등장 | Stage는 인물ID와 해당 시점의 표시 정보를 참조. C01의01 훈련병/30 이병, C02~C05의 부대/대회 대사를 구분. |
| 표시 | name/rank/role/service/round 문자열은 Strings ko/en에서 가져온다. 전체 표시명도 현지화 키로 관리해 영어 어순을 한국어와 같게 붙이지 않는다. |
| 승패 | aiIntroKey/aiWinKey/aiLoseKey의 기존 의미 유지. 첫 대국 승리·24초대·30결말에 단계별 키를 쓴다. |
| 이미지 | 승인된3상태를 저장된 프리팹/테마에 직렬화해 연결. 단계번호를 나눠 얼굴을 정하는 이전 계급 매핑을 새 인물 매핑으로 오인하지 않는다. |
| 상태 | 도입→대국→AI 패배가 실제 상태와 일치. AI 승리 때 패배 그림을 보이지 않고 재도전·언어 변경·로비 복귀에 이전 상대의 그림/대사를 남기지 않는다. |

검수는 한영에서 긴 보직+이름·공군·라운드가 잘리지 않는지,01/30의C01이 동일 인물인지, 대회6명 모두 병사인지,24초대가23에 나오지 않는지, 마지막에31로 연결되지 않는지 확인한다. 기획과 신규18개 기본 이미지 및13개 군모 변형 이미지 생성·파일 검사를 완료했다. Excel·프리팹 연결, 빌드·브라우저·실기기 검증은 수행하지 않았다. 생성 원본을 보존하고 사용자가 이미지 검토 후 확정한 버전을 연결한다.
