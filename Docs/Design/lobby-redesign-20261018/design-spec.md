# 로비 임무 카드와 상단 아이콘 — 2026-10-18

사용자 지시: 하단은 멀티 배틀만 유지한다. 광고 제거는 도움말 옆 이미지 아이콘으로 옮기고, 도움말·설정·광고 제거의 큰 배경을 없앤다. 스테이지 카드와 멀티 배틀을 군부대 도트 콘셉트로 다듬고 멀티 오른쪽에 내 레이팅을 표시한다.

## 배치

```text
                 이겨도 됩니까?

  ?  [광고 없는 영상 문양]                       ⚙

  ┌ 01단계 ───────────── › ┐  ┌ 02단계 ─────── 잠금 ┐
  │     훈련병 강민재       │  │      이병 문시온      │
  │   난이도 별            │  │      난이도 별        │
  │        Rating 200      │  │       Rating 200      │
  └───────────────────────┘  └─────────────────────┘
                 두 줄과 다음 줄의 일부

  ┌ 흑백 돌    멀티 배틀               │ Rating 200 ┐
  └────────────────────────────────────────────────┘
```

- 720 기준 좌표에서 하단 버튼은 구매 여부와 무관하게 680×110. 좌측 흑백 돌 문양, 가운데 행동명, 오른쪽 레이팅을 분리한다. 오른쪽 영역도 같은 멀티 진입 버튼의 일부다.
- 도움말/광고 제거/설정은 110×110 투명 입력 영역을 유지한다. 보이는 바탕은 없고 아이콘만 표시한다. 광고 제거는 글자를 감춘 독립 PNG다. 도움말·설정은 어두운 도트 본체와 크림색 사방 외곽선을 사용한다.
- 상단 아이콘 행은 목록과 함께 높이를 계산하고, 짧은 화면에서도 제목과 겹치지 않도록 최소 상단 간격을 확보한다. 호스트 여백이 큰 작은 화면에서는 목록의 보이는 줄 수가 줄어든다.
- 카드는 기존 2열과 스크롤을 유지한다. 종이색 테두리·상단 보직표 느낌의 번호 띠·세로 강조선·난이도와 레이팅 구획을 둔다. 현재 단계는 황토색 띠와 화살표, 완료는 체크, 잠금은 자물쇠로 구분한다.
- Pretendard와 기존 배경·흑백 돌을 유지한다. 다른 패널의 공통 테마를 바꾸지 않고 새 로비 전용 스프라이트를 저장한다.

## 레이팅

- 서버 본인 `state` 또는 읽기 전용 `GET /v1/profile` 값만 표시한다. 초대 미리보기의 상대 점수는 사용하지 않는다.
- 신규 저장은 초기 200점, 기존 계정에 확인된 값이 없으면 `—`를 표시한다. 시작 및 일정 간격 후 앱 복귀 때 조회하며 결과·퇴장 후에도 본인 확정 값을 유지한다.
- 조회는 등록·소켓 인증·연결 교체·게임 상태 변경·저장 쓰기를 수행하지 않는다. 다른 탭 대국을 끊지 않는다.
- 네트워크 일시 실패는 마지막 확인값을 유지하되 계정 식별자가 바뀌거나 401인 경우 이전 계정 점수를 표시하지 않는다. 캐시는 식별자 해시와 연결한다.
