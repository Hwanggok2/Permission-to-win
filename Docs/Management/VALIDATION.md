# 재미·시장성 검증 기준

아래 수치는 이번 MVP의 내부 판단 목표이며 시장 평균이나 수익 보장이 아니다.

## 첫 플레이 검증 (D2)

5명 목표로 최소 3판씩 관찰한다. 개인정보 없이 익명 P01~P05로 기록하고 동의 없이 외부 전송하지 않는다.

| 질문 | 통과 목표 | 기록 |
| --- | --- | --- |
| 설명 후 규칙을 이해하는가 | 5명 중 4명, 30초 안에 첫 합법 수 | 소요시간/막힌 지점 |
| 판이 짧고 판단 여지가 있는가 | 관측 판 중앙값 45~120초 | 종료 이유/수 수/소요시간 |
| 다시 하고 싶은가 | 5명 중 3명이 권유 없이 추가 판 시작 | 실제 행동 + 이유 |
| 패배 이유를 납득하는가 | 5명 중 4명 | 짧은 주관식 |
| UI를 누르기 편한가 | 보드/광고 버튼 오터치 0 목표 | 기기/해상도/문제 위치 |

실패하면 먼저 튜토리얼, AI 예산, 초기 배치/스테이지를 조정한다. 광고를 늘려 낮은 재도전을 보완하지 않는다.
5명은 정성 검증이며 유지율·매출·통계적 유의성을 증명할 수 없다.

## 출시 후 관측 설계

- 이벤트 후보: tutorial_complete, stage_start/end(stage_id, outcome, duration), retry, ad_request/show/close/fail, reward_granted.
- MVP 기본은 로컬 진단 로그. 원격 분석 도입은 SDK/개인정보 문서·동의 요건 확인 이후 별도 작업.
- D1/D7 재방문, 평균 세션, 스테이지별 도달/승률, 광고 이후 종료, 요청 대비 노출, 오류/충돌을 관측한다.
- 초기 대안: 광고 없음과 간격 적용의 재도전 차이를 먼저 비교. 배너는 로비/결과 고정 공간, 대국 영역과 분리.
- 수익 민감도 공식: 일 노출 수 × 실효 eCPM ÷ 1000. 광고 형식/플랫폼별 실제 값을 분리하고 정산 수수료·세금·운영비를 별도 반영. 아직 유효 노출수/eCPM 관측이 없어 금액 예측을 제시하지 않는다.

## 범위 제한

스토어 경쟁작 설치수는 기존 수요의 단서이며 우리 게임의 획득비·유지율·시장성을 증명하지 않는다.
처음에는 자체 시각 요소와 짧은 AI 스테이지 진행을 검증하고, 온라인 대전/랭킹/계정/유료 상품은 넣지 않는다.
