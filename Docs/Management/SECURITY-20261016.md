# 외부 출처 HTML의 Mapbox 토큰 경고 — 2026-10-16

GitHub Secret scanning이 `Client/Archive/Audio/RecordedStone/freesound-source.html`의 지도 스크립트에서 Mapbox 토큰을 감지했다. 효과음 `GoStoneSounds.ogg`의 CC0 출처 증빙을 위해 보관한 Freesound 페이지에 포함된 값이다. 원문 토큰은 이 문서에 기록하지 않는다.

확인한 값은 `pk` 접두사의 공개용 토큰이며 계정 필드는 `freesound`다. [Mapbox 공식 문서](https://docs.mapbox.com/help/getting-started/access-tokens/)는 `pk`를 공개용, `sk`를 비밀용으로 구분한다(확인일 2026-10-16). 이번 경고는 StageGame의 서버·결제·GitHub 비밀키를 발견했다는 증거가 아니다. 외부 사이트의 공개용 값도 우리 저장소에 보관할 필요가 없으므로 제거한다. 해당 토큰으로 API 호출, 권한 검사, 폐기를 시도하지 않는다.

현재 추적 파일 4,261개, 보관 ZIP 5개 내부, Pages 배포 브랜치 20개 파일에서 Mapbox `pk/sk/tk` 형식을 검사해 이 HTML의 1건만 확인했다. Pages 빌드에는 포함되지 않았다. HTML의 값만 대체하고 정제 표시·출처 메타데이터를 추가했으며, 효과음·저작자·원문 출처 URL·CC0 증거는 유지했다. 이 검사는 Mapbox 토큰 형식에 한정되며 모든 종류의 비밀정보 부재를 보증하지 않는다.

정제 후 같은 범위를 재검사해 해당 형식의 일치는 0건이었다. 수정 파일의 Git 공백 검사도 통과했다. Unity 런타임·음원·Pages 배포 파일은 변경하지 않았으며 새 게임 빌드는 하지 않았다. 로컬 Git 인증은 확인되지 않아 수정 커밋의 원격 푸시는 대기다.

현재 파일을 정제해도 이전 커밋에는 원문이 남는다. 이 변경은 과거 Git 이력을 재작성하거나 GitHub 경고를 닫는 작업을 포함하지 않는다. 경고 분류·닫힘 상태와 수정 커밋의 원격 반영 여부는 별도로 확인해야 한다. 외부 페이지 원문을 보관할 때 실행용 스크립트·인증값이 함께 저장될 수 있다는 점을 검토 범위에 추가한다.

사용자 첨부 화면에서 Secret scanning `0 Open / 1 Closed`를 확인했다. 해당 경고는 닫힌 상태이며 처리 이력은 남는다. 상단 Security 숫자1만으로 재개방을 판정하지 않는다. 새로고침 후 다른 보안 항목도 구분해서 확인한다. 이 화면 확인은 토큰 폐기나 과거 Git 이력 삭제를 뜻하지 않는다.
