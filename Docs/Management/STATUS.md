## 현황

- **최신 v10 작업:** 차례 알림 텍스트만·AI 활성 시간 1초 대기·1080×1920 기준·훈련병 군모·로비/인게임 상단 높이 정렬을 구현 중이다. 한 수 진급은 제거하고 개발 표시명 4목/Four in a Row로 임시 교체한다. Connect 4 이름 사용은 제외했으며 권리 검토 상태를 별도 정리한다. 소스/Unity 확인까지만 진행하고 사용자 승인 전 새 웹·Android 빌드나 브라우저 실행은 하지 않는다.
- **v9 독립 QA:** 실제 후보 소스 40묶음·0실패. QA-014 파괴 후 광고 콜백, 확인 취소/수락 1회, AI 재개, 토스트 수명, 첫 대사 한영/승패 연결 회귀 통과. 실행 후 변화는 승인 조건을 추가한 관리 계약뿐이며 제품 소스 변화는 없다. 브라우저 새 실행은 승인 대기 상태다.
- **승인 대기:** 최종 v9 Unity 73/73 및 모자/한영/안전영역 캡처 완료, `rank-v9-source-freeze.json` 동결. 사용자가 이번 웹 빌드는 승인 후 진행하도록 지정했다. 확인 시 이미 시작된 웹 빌드 파일은 갱신된 상태였으며 총괄 브라우저 새 실행은 미실행이다. 이후 재빌드·브라우저 테스트는 승인 전 보류한다.
- **스토리 추가:** 사회에서 4목 프로였던 플레이어가 입대한 훈련병이라는 설정을 확정했다. 첫 상대 원문과 승패 도발·인정 대사를 Excel 한영으로 작성했고 237문구·44개 데이터 검사를 통과했다. v9 말풍선 연결·렌더 검증 중이다. [설정](../Design/STORY.md) · [데이터 계약](../../GameData/STORY-CONTRACT.md). v8 독립 QA의 늦은 광고 콜백 결함 QA-014는 클라이언트에 전달했으며 v9 수정·재시험 대상이다.
- **최신 작업 v9:** v8 흑백 계급 UI의 Unity 67/67과 WebGL 빌드(오류/경고 0)를 마친 직후 사용자 추가 지시 도착. 정사각형 판/칸·선 두께 통일·토스 예약 영역 바로 아래 헤더·모자 쓴 중앙 AI 행·차례 팝업·원형 놓기·로비/다시하기 확인 패널을 구현 중이다. 아래 v8 증거를 v9 통과로 사용하지 않는다. 사용자 답변으로 현재는 브라우저만 시험하며 휴대폰 시험은 보류한다.

- **현재 작업 v8:** 사용자가 크림/청록 시안을 거절해 흰 격자판·흑백 돌, 큰 2열 계급 카드·우측 상세 패널·AI 말풍선·미리보기/놓기/되돌리기로 다시 제작 중이다. 중력식 4목과 멀티플레이 준비 중 표시를 사용자 답변으로 확정했다. 신규 첫 실행 자동 시작과 승리 다음 단계를 추가하며 이전 결과 두 버튼 제한을 대체한다. 클라이언트·Excel·기획·QA에 위임, 총괄은 통합/브라우저 검증을 담당한다. 실제 휴대폰 시험은 미실행이다.
- **직전 시안:** Tabletop UI는 Unity 59/59, 별도 에디터 보호 1/1, 두 개발 빌드 및 WebGL 승패/잠금/한영/복원 검증을 마쳤으나 시각 디자인은 사용자 불수용이다. 새 UI와 구분해 [이전 증거](Evidence/graphics-refresh-browser-20261014/README.md)를 보존한다.
- **v8 데이터 완료:** 한영 228개(기존 90개 보존·47개 수정·91개 추가), 10계급·별점·단계 설명·AI 대사 필드와 시작하기/대국 시작 분리. 설명/대사 최대 한국어 22자·영어 41자. 기존 ID·시작판·AI·광고 보존, 데이터 42개 및 반복 생성/검증 통과. [인계](../../GameData/RANK-UI-CONTRACT.md). 새 화면·상호작용 통과와 구분한다.

- 최신 UX: 챕터별 10개 노드·완료/도전/잠금·선택 표시, 그림 규칙, 승리 다음/패배 재도전 강조와 호환 완료 저장을 구현했다. Unity 전체57/57 및 독립 저장8묶음·화면/광고/언어26묶음 통과. 실제 브라우저390↔320 한영·잠금·챕터·9수 재승리·10수 패배·다음/재도전·언어/진행 복원을 확인했다. 가려진 판을 보라는 안내를 찾아 Excel 3문구를 줄이고 영향11/11·두 플랫폼 재빌드·최종 브라우저 패배 재시험을 마쳤다. 57개와11개는 별도 실행이다. [최신 증거](Evidence/reference-ux-browser-20261014/README.md), [QA](../QA/STAGE-UX-RESULTS.md), [참고 분석](../Design/REFERENCE-UX.md).

Unity 전체49/49·입력 경계8/8·최종 UI1/1(중복 있음), 두 개발 빌드 오류/경고0. 모의 브라우저390↔320·대국 입력·설정 언어·라이선스 전문/닫기 확인. [최신 증거와 범위](Evidence/host-ui-browser-20261014/README.md), [상세 QA](../QA/HOST-UI-RESULTS.md).

- 브라우저에서 한영 전환·새로고침·영어 승리 결과를 확인했다. 크기 변경 시 버튼이 과소 축소되는 QA-008은 수정 및 Unity 회귀 통과, 최종 브라우저 390↔320 재시험·언어/닫기 입력도 통과했다. [증거](Evidence/localization-browser-20261014/README.md). 실기기/사람/광고·결제 미검증으로 출시 판정은 보류한다.

## 출시 차단 기준

- 실제 플레이·저장·프리팹·광고 테스트 증거 없이 출시 완료 처리하지 않는다.
- 상품 판매에는 소유자 검증·중복 지급 방지·복구·환불·장애 테스트가 필요하다. 결제 추가로 일정 여유가 줄었으므로 장식·추가 콘텐츠부터 줄이고 거래 검증은 생략하지 않는다.
- 광고 계정/앱 ID/개인정보 표시/서명/등급 증빙 미비는 해당 제출을 차단한다.
- 종목별 재미 검증이 실패하면 D2까지 범위/난이도 조정. D3 이후 새 종목/온라인 기능 추가 금지.
