## 현황

- 역할별 조사 후 7×6 중력식 4목을 확정. Client는 실제 Unity/프리팹/게임 구현, GameData는 Excel·exporter·30스테이지 제작 중.
- Unity 6000.3.15f1와 Android/WebGL 모듈 설치 확인. 실제 빌드는 아직 미검증.
- 원스토어 판매자 계정과 앱인토스 워크스페이스: 사용자 준비 완료 확인(10/14). 실제 콘솔 접속/앱별 등록 상태는 미검증.
- 기존 GitHub `https://github.com/Hwanggok2/StageGame.git` 연결 및 초기 커밋 `ec0aa9c` 확인. 로컬 작업파일을 보존하면서 main을 origin/main에 연결. 푸시 확인 대기.
- 광고 계정/앱별 ID, Android 서명 정보: 확인 필요.
- SDK 실제 통합/빌드/기기 테스트/재미 검증/스토어 제출: 아직 수행하지 않음.

## 출시 차단 기준

- 실제 플레이·저장·프리팹·광고 테스트 증거 없이 출시 완료 처리하지 않는다.
- 광고 계정/앱 ID/개인정보 표시/서명/등급 증빙 미비는 해당 제출을 차단한다.
- 종목별 재미 검증이 실패하면 D2까지 범위/난이도 조정. D3 이후 새 종목/온라인 기능 추가 금지.
