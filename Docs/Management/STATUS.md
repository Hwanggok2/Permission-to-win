## 현황

- 역할별 조사 후 7×6 중력식 4목을 확정. 30개 스테이지, 오프라인 AI, 해금/저장, 무료 재도전, 도움말/설정, 저장된 UI 프리팹 구현.
- Unity 6000.3.15f1에서 테스트 30개 통과 및 Android APK/WebGL 개발 빌드 성공. 이것은 릴리스 서명·실기기·토스 실행 완료를 뜻하지 않는다.
- 독립 QA 코어 21그룹 통과. 초기 진행 불가 국면을 수정해 30개 모두 실제 AI 정책에 대한 승리 예시를 확보했다. 기기별 650ms 탐색 중단, 사람 체감 난이도·재미는 별도 검증 대상이다.
- Excel 원본과 Generated/Client JSON 3파일 일치 확인. exporter 교체 실패 복구를 수정했고 28테스트 및 독립 실패 주입 재검증을 통과했다. 프로세스 강제 종료까지 파일 묶음 원자성을 보장하지는 않는다.
- WebGL 자홍색 UI 결함을 필수 UI 셰이더 포함으로 수정했다. 총괄의 실제 브라우저 smoke에서 세로 로비, 대국 시작, 착수·AI 응수, 광고 NoFill 진행 유지, 나가기, 설정, 라이선스 전문·스크롤·닫기를 확인했다. 관찰 구간 콘솔 오류/경고 0. 데스크톱 검증이며 모바일 토스 검증과 구분한다.
- 390×844 브라우저 크기에서 우측 잘림을 찾아 CSS를 수정했다. 최종 캔버스 390×693.333으로 전체 UI 표시, 첫 스테이지 9수 승리, 2/30 해금, 새로고침 후 2스테이지/해금 복원을 실제 입력으로 확인했다. 잘못 판독한 라이선스 X 좌표는 정확한 위치에서 정상 닫힘을 재확인하여 제품 결함으로 처리하지 않았다.
- Noto 폰트·uGUI 고지 전문을 배포본 및 설정 내 라이선스 화면에 포함했다. 출처 대장 및 최종 APK 포함 증거는 Licence/와 Client/Evidence/를 따른다.
- [상점 아이콘 원본 초안](StoreAssets/README.md)을 외부 이미지·폰트 없이 제작. 최종 브랜드·상점 규격·앱 적용 전 초안이다.
- 원스토어 판매자 계정과 앱인토스 워크스페이스: 사용자 준비 완료 확인(10/14). 실제 콘솔 접속/앱별 등록 상태는 미검증.
- 기존 GitHub `https://github.com/Hwanggok2/StageGame.git` 연결 및 초기 커밋 `ec0aa9c` 확인. 로컬 작업파일을 보존하면서 main을 origin/main에 연결.
- 로컬 기초 커밋 `8e8d740`, 게임/데이터 개발판 커밋 `e0accc3` 완료. 원격은 Public 상태. 자동 승인 검토에서 기획/워크플로 문서 공개 업로드가 거절되어 미전송. [공개 범위](PUBLISH-REVIEW.md)에 대한 승인 질문을 전달했다.
- 파일 전송 없는 `git push --dry-run`도 인증 없음으로 실패. GitHub 쓰기 인증이 별도 필요; 토큰/비밀번호를 채팅이나 Git에 기록하지 않는다.
- 광고 계정/앱별 ID, Android 서명 정보: 확인 필요.
- AdMob 공식 지원 스토어 목록에 원스토어 없음. 원스토어만 등록한 앱은 심사 대상/정상 송출로 가정하지 않는다. [근거](https://support.google.com/admob/answer/9989980) (확인 10/14).
- 실제 광고 SDK/토스 SDK·`.ait`, Android 실기기 설치/검증, 사람 재미 검증, 릴리스 서명/스토어 제출: 아직 수행하지 않음. 현재 광고 서비스는 NoFill이며 수익을 발생시키지 않는다.
- ADB로 확인한 연결 Android 기기는 0개. APK가 생성된 사실과 휴대폰에서 동작한 사실을 구분한다.
- QA 최종 체크포인트의 확인된 열린 제품 결함은 0건이다. 미실행 영역까지 무결함이라는 의미가 아니며 출시 판정은 보류한다.
