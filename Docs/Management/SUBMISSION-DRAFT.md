## 제출 묶음

- Android: 실제 검증한 릴리스 APK/AAB 등 현재 콘솔이 요구하는 형식, 버전, 서명, 변경 내역.
- 원스토어: 게임 설명/등급 설문/검토 자료, 실제 플레이 캡처, 앱 아이콘, 문의/개인정보 URL.
- 토스: 동일 게임의 등급 증빙/스토어 링크, 최신 지원 SDK로 만든 .ait, 앱 등록 정보, 광고 설정/테스트 증거.
- 공통: 라이선스 고지 파일, QA 보고서, 파일 해시, 회귀 결과, 알려진 이슈.

준비된 비개인 자료: [아이콘 원본 초안](StoreAssets/README.md), `Client/Evidence/`의 실제 실행 화면, [구현상 저장·권한·통신 사실](DATA-FLOW-DRAFT.md). 최종 등록자 정보·규격·실기기 검증이 필요하다.

## 사용자 확인이 필요한 정보와 시점

1. 원격 코드 업로드: 지정 GitHub 저장소가 Public임을 확인. 소스·엑셀·기획/QA 문서 공개 범위 승인 후 업로드.
2. 실제 광고 연결: 사용할 플랫폼의 앱/광고 단위 식별자와 승인 상태. 비밀 인증정보는 로컬 안전한 설정 수단 사용.
3. 스토어 등록 직전: 최종 게임명, 문의 이메일, 앱 식별자, 개인정보 문서, 서명, 등급/콘솔 입력 확인.
4. 실제 기기/재미: 사용자 또는 모집된 테스터의 플레이 증거. 자동 테스트만으로 대체하지 않는다.

계정 준비 완료는 사용자에게 확인했다. 앱별 등록·계약·광고 승인·서명·등급 증빙 발급을 확인했다는 뜻은 아니다.

원스토어 첫 무광고 버전은 광고 제거 상품을 판매하지 않는다. 토스 수익화 버전은 구매자와 주문의 소유 관계, 구매/복구/환불, 광고 차단·무료 힌트를 검증한 뒤 구매 문구를 상점에 반영한다. 미결 주문 복구만 확인하고 재설치 후 영구 구매 복구까지 완료로 표시하지 않는다.
