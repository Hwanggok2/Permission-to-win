# 참고 UX 반영 브라우저 검증

2026-10-14 총괄. 로컬 WebGL 개발 빌드에 실제 포인터를 입력해 검사한다. 실제 토스 SDK·휴대폰·사람 사용성 시험과 구분한다. 참고 게임 스크린샷은 분석 입력이며 이 폴더와 게임 빌드에 복사하지 않는다.

## 검사 범위

- 390×844 및 320×568 CSS px, 위 inset 59·아래 34·좌우 0. 모의 상단 예약선은 123px이며 공식 토스 버튼 높이를 뜻하지 않는다.
- 로비: 완료·현재·잠금·선택 상태, 챕터 1→2→3→1, 잠금 안내와 시작 차단, 이전 완료 단계 재도전.
- 도움말: 중력과 네 개 연결 그림, 캡션, 한영 표시와 닫기.
- 저장/대국: 승리 이후 다음 단계 및 완료 표시, 새로고침 후 복원, 주요 결과 행동. 30단계 완료·옛 저장 migration은 자동 검사와 구분해 기록.
- 기존 보조 흐름: 설정 언어와 라이선스 진입, 호스트 상단 영역, 화면 크기 변경, 콘솔 오류/경고.

## 실제 입력 결과

- `before-lobby-390.jpg`는 개선 전 한 장 선택 방식이다. `ko-map-390.jpg`에서 완료 1·현재 도전 2·잠금 3~10과 선택 표시가 구분된다. 옛 저장을 읽어 2단계 해금에서 1/30 완료로 표시했다.
- 3단계를 선택하면 선행 2단계 안내가 나오고 시작 버튼 클릭이 판을 열지 않았다. 챕터 1→2→3→1 이동, 30단계 선택과 29단계 선행 안내를 확인했다. [잠금](ko-locked-390.jpg) · [마지막 챕터](ko-chapter3-390.jpg).
- 390→320→390 변경과 한국어/영어 화면에서 열 개 노드, 선택 카드, 버튼, 그림/캡션이 모두 보였다. 캔버스는 CSS viewport 전체와 일치했다. 버튼 치수의 수치 근거는 Client Unity 렌더 검사(노드 약51px·일반 약47px)이며 브라우저 스크린샷만으로 치수를 판정하지 않았다. [한국어 320](ko-map-320.jpg) · [영어 320](en-map-320.jpg) · [영어 도움말](en-help-320.jpg).
- 영어 설정 후 새로고침에서 영어·2단계 해금·완료1이 복원됐다. 완료1을 선택해 실제 9수 승리 후 강조된 다음 버튼으로 2단계에 진입했다. [승리](en-win-next-390.jpg) · [복원](en-restored-390.jpg).
- 2단계의 실제 10수 패배에서 재도전이 주요 버튼으로 표시됐고, 클릭하면 2단계 초기 4수 배치로 돌아왔다. [패배](en-loss-retry-390.jpg) · [재시작](en-retry-stage2-390.jpg). 위 승리는 이미 완료한 단계의 재도전이므로 새 완료 수 증가를 검사한 것으로 표현하지 않는다.
- 쉼→나가기, 설정의 라이선스 진입·스크롤·닫기, 한국어 복귀를 확인했다. 이번에는 고지 끝까지 재검사하지 않았으며 기존 전문 포함/끝 문단 검사는 이전 증거와 구분한다. 관찰 구간 콘솔 오류·경고 0(`console-before-copy-fix.json`).

## 발견한 문구 문제와 최종 재검사

패배 모달이 판을 가리는데 기존 문구는 “금색 줄을 살펴보세요”라고 안내했다. 총괄이 방향별 안내 3개의 둘째 줄 삭제를 승인했고 Excel에서 수정했다. 기존 120개 문구 보존 + 승인 수정 3개 + 신규 14개 = 총137개다. 위 기능/화면 검사는 이 문구 수정 전 빌드이며 코드·프리팹 변경은 없다.

최종 문자열 SHA-256은 `57E392CF68464898829946F17030E4AE3008AAB86370452BACF6DBE56D68A291`이며 Generated와 Client가 같다. Client의 전체57개 검사와 문구 수정 후 영향11개 검사는 별도 실행이다. 최종 두 개발 빌드가 성공했고, 총괄이 **최종 WebGL을 새로 불러와** 2단계의 동일한 10수 패배를 다시 만들었다. 세로 연결 안내 한 문장과 재도전 버튼이 정상 표시됐다. [최종 패배](final-ko-loss-390.jpg) · [최종 로비](final-ko-map-390.jpg) · [최종 도움말](final-ko-help-390.jpg). 최종 관찰 콘솔 오류/경고 0(`final-console.json`).

`before-copy-fix-artifacts.json`은 첫 UI 기능 검사 빌드이며, `final-artifacts.json`은 문구 수정 후 빌드다. 최종 데이터 검사에서 방향별3개×한영의 정확한 한 문장을 확인하며, 총괄 포인터 재시험은 한국어 세로 패배 하나다. 가로/대각선·영어 패배를 최종 브라우저에서 모두 재현했다고 주장하지 않는다. 두 단계의 소스/범위는 [독립 QA](../../../QA/STAGE-UX-RESULTS.md)에 연결한다.

Overview는 최종 로비/도움말 캡처를 사용한다. 데스크톱 시각 확인과 320px 문서의 가로 넘침 없음(문서 가용 폭305px=scrollWidth), 이미지4개 로드를 확인했다. 임시 viewport를 해제하고 게임의 모의 호스트 표시를 끈 기본 URL로 복귀했다.

30단계 완주·무승부·구형 raw 저장의 경계는 Unity 및 독립 대체 환경 검사이며, 이번 브라우저에서 모든 단계를 플레이한 결과가 아니다. [클라이언트 검증](../../../../Client/Evidence/stage-map-verification.json) · [독립 QA](../../../QA/STAGE-UX-RESULTS.md).

지원 확인 범위를 벗어난 가용 공간·가로 화면·실제 호스트 버튼 위치·모바일 성능·사람 재미는 이 브라우저 검사로 보장하지 않는다.
