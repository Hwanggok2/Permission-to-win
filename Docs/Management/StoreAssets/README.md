# 상점 자산 초안

`icon-draft.svg`는 사각형과 원으로 직접 작성한 원본이다. 외부 아이콘·이미지·폰트를 사용하지 않았다. 같은 도형을 `generate_icon.py`로 PNG 1024/512px로 렌더했다. 민트색 네 돌의 연결과 산호색 상대 돌을 게임 화면의 색상으로 표현한다.

최종 브랜드/상점 규격 확인 전 초안이며, 현재 APK 아이콘을 교체하거나 스토어에 제출하지 않았다. 런처 adaptive icon과 플랫폼별 상점 이미지는 제출 규격 확정 후 각각 적용한다.

실제 게임 화면 증거는 `Client/Evidence/`에 있다. 에디터 렌더와 브라우저 캡처를 Android 실기기 사진으로 표기하지 않는다. 최종 상점 설명은 [제출 초안](../SUBMISSION-DRAFT.md)을 따른다.
