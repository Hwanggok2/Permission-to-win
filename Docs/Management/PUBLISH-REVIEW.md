# GitHub 공개 업로드 검토 범위

대상: `https://github.com/Hwanggok2/StageGame.git`, `main`. 2026-10-14 GitHub 페이지에서 Public 상태를 확인했다. 업로드하면 아래 소스와 제작 정보가 누구에게나 공개된다.

## 준비된 업로드 내용

- `Client/Assets`, `Packages`, `ProjectSettings`, 제작/동기화 도구: 게임 코드, 저장된 씬·프리팹, 자체 도형·효과음, OFL 폰트 및 고지, 데이터 임포트.
- `GameData`: Excel 원본, 30개 국면과 AI 값, 광고/문자열 설정, JSON 내보내기 도구 및 검증 자료.
- `Server`: 현재 서버를 사용하지 않는 MVP 범위 문서.
- `Docs`, `Licence`, `Tests`: 기획·시장성 가설·일정·출시 요건, 라이선스 대장, QA 코드/결과/소스 스냅샷·화면 증거, 아이콘 초안.
- 루트 협업 규칙, README, Git 제외/텍스트 규칙.

## 제외 및 상태

Library·임시 폴더·로그 원본·APK/WebGL 빌드 폴더·서명키·환경 비밀 설정은 Git 제외 규칙에 포함했다. 소스/설정/문서의 흔한 개인키·GitHub 토큰·AWS/Google 키 패턴 검색은 일치가 없었다. 이는 전체 보안 검토나 비밀정보 부재를 보증하는 검사가 아니다.

원격 연결·초기 커밋 가져오기와 로컬 저장은 완료했다. 공개 업로드를 시도한 동작은 자동 승인 검토가 내부 제작/기획 자료 공개 범위의 구체적 승인이 부족하다는 이유로 거절해 실행하지 않았다. 또한 비대화형 push dry-run은 쓰기 인증 부재로 실패했다. 실제 push는 공개 범위 승인 및 GitHub 인증 후 진행한다. 토큰/비밀번호/서명키를 채팅 또는 문서에 입력하지 않는다.

기존 원격 기록을 보존하며 force push를 하지 않는다. 이 확인은 소스 공개 범위에 대한 것이며 스토어 공개·광고 활성화 승인과는 별개다.
