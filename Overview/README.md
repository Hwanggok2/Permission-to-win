# 이겨도 됩니까? — 전체 계획

**글꼴 적용 2026-10-16:** 제목·기본 UI는 **Pretendard**, 네오둥근모 Pro는 도트 연출용으로 추가했다. 프리팹 글꼴 참조 81개를 변경하고 Unity 12/12·한영 캡처 78장을 확인했다. 공식 원본·라이선스 전문·출처/해시를 관리하며 위 최신 공개 빌드에 반영됐다. [적용·라이선스 기록](../Docs/Design/TYPOGRAPHY.md).

**게임명 확정 2026-10-16:** 한국어 **이겨도 됩니까?**, 영어 **Permission to Win**, 제작사 **사부작대작전**, 저장소 **Permission-to-win**. Excel 원본·클라이언트·웹 템플릿의 제목을 갱신했고 데이터 46/46·Unity 11/11을 확인했다. 위 최신 WebGL 공개 빌드에 제목을 반영했다. 원격 이름의 대소문자 처리와 검증 구분은 [게임명 적용 기록](../Docs/Design/GAME-TITLE.md)을 따른다.

**상세 패널 중앙 배치 2026-10-16:** 단계 번호·닫기·판·설명·시작하기를 안전영역 중앙에 배치했다. 작은 화면은 기존 스크롤을 유지하며 영어 설명은 두 줄까지 표시한다. Unity7/7·24조합 검사 완료. 당시 소스 수정까지만 유지했으며, 이후 사용자 요청에 따른 위 최신 제목·폰트 WebGL 빌드에 함께 반영했다. [수정 화면·검증](../Docs/Management/Evidence/detail-centered-20261016/README.md).

**배경 시안 2026-10-15:** 관물대·평상·창문이 보이는 낮은 디테일의 도트 내무반을 추가했다. 캐릭터 뒤에 배치하고 보드는 흰색을 유지하는 [독립 화면 미리보기 v13](assets/military-pixel-20261015/preview-v13.html)에서 시작·대국 중·AI 패배를 비교한다. 이미지 승인 전이며 실제 게임 연결·빌드는 하지 않았다. [생성 및 검증 기록](assets/military-pixel-20261015/barracks-v13-record.json).

**최신 디자인 검토 2026-10-15:** 훈련병은 까까머리·긴소매 군복의 거친 도트 캐릭터로 검토한다. 정면을 가리키는 시작 대사 → 오른손을 살짝 펴고 왼팔을 책상에 얹는 대국 자세 → 양팔을 몸 앞쪽으로 들어 하늘에 외치는 패배 반응을 [독립 화면 미리보기](assets/military-pixel-20261015/preview-v12.html)에서 비교할 수 있다. 사용자 지시에 따라 **이미지 확정 전 게임 연결 중단**, 작성 중이던 연결 코드는 별도 초안으로 분리하고 Assets는 이전 상태로 복원했다는 클라이언트 보고를 확인했다. 게임 구현·애니메이션 실행·새 빌드의 증거가 아니다. 기존 로비·계급·난이도 변경은 유지한다.

**권리 재확인 2026-10-15:** 기본 4목 규칙의 독자적인 상업 개발은 유지한다. KIPRIS에서 `4목` 완전일치 결과 없음, 과거 `4목게임` 2건의 소멸·포기와 `사목` 관련 등록 표장 2건을 실제 조회했다. 제목과 최종 화면 전체의 무침해 확정은 아니다. [저작권 판단과 상표 조회 근거](RIGHTS-REVIEW.md).

**현재 v10 수정 중:** 배경 없는 내 차례 텍스트, AI 약 1초 대기, 1080×1920 기준 배치, 훈련병 군모 재제작, 로비와 인게임의 상단 위치 통일. 개발 표시명은 한 수 진급을 제거하고 **4목 / Four in a Row**로 임시 변경한다. Connect 4 상품명은 사용하지 않으며 이름 변경만으로 상용 권리가 확보됐다고 판정하지 않는다. 새 웹 빌드와 실행은 사용자 승인 전 보류한다. 아래 v9 검사 수치는 이전 버전 이력이다.

**소스 수정만 유지 · 웹 빌드 미실행:** 최종 v9 Unity 73/73 검사와 화면 캡처 완료. 이후 사용자 승인 조건을 받았으며, 확인 당시 이미 시작된 웹 빌드 파일은 갱신된 상태였다. 총괄은 새 브라우저 실행을 하지 않았다. 재빌드·새 결과 실행은 승인 전 보류한다.

검증은 Unity 73/73, 독립 소스 QA 40묶음/0실패, Excel 44개로 구분한다. QA-014 재현 회귀도 통과했다. 독립 실행 후 바뀐 파일은 승인 조건을 추가한 관리 계약뿐이며 제품 코드/데이터 변화는 없다. [현재 QA 결과](../Docs/QA/RANK-UI-RESULTS.md).

**현재 작업 v9:** 흑백 계급 UI의 Unity 67개 검사와 WebGL 빌드 후, 사용자 추가 지시를 반영 중이다. 정사각형 판·같은 칸 간격·상단 제목/일시정지, 모자 쓴 AI의 중앙 행, 차례 팝업, 원형 놓기, 로비/다시하기 확인 패널을 추가한다. 휴대폰은 사용자 요청으로 보류하고 브라우저만 시험한다. [구성안](assets/rank-flow.svg)은 v8 계획도이며 새 빌드 캡처가 아니다.

| 일정 | 10/15 재미·상품 확인 → 10/16~18 광고·결제·서버 연동 → 10/19 QA → 10/20 동결 → 10/21 제출 준비 목표 |
| 권리 | 자체 코드·도형·효과음, OFL 폰트·uGUI 고지. 최종 이름·SDK 조건·등급·개인정보·서명 확인 |

## 완료와 남은 일

**기존 개발판 검증:** 30스테이지·AI·저장·한영·호스트 여백·라이선스와 두 플랫폼 개발 빌드가 있다. 이전 크림/청록 시안은 Unity 59개, 별도 에디터 보호 1개와 실제 WebGL 입력을 검사했다. 해당 시안은 사용자가 거절했으며 이 결과를 새 흑백 UI의 완료 근거로 사용하지 않는다. [이전 시안 증거](../Docs/Management/Evidence/graphics-refresh-browser-20261014/README.md).

**다음:** 실제 광고, 광고 제거 구매/복구/환불, 서버 배포, 토스 SDK·`.ait`, 실기기·사람 검증. 기존 테스트 통과가 새 결제 기능 검증을 뜻하지 않는다. 심사 승인 날짜는 별도다.

## 운영 기준

- 구매는 **같은 플랫폼 계정**에서 복구. 원스토어↔토스 구매 공유와 게임 진행 클라우드 동기화는 제외한다.
- 구매 검증 전 중복 결제를 유도하지 않고, 통신 실패만으로 기존 구매 권리를 회수하지 않는다. 환불·취소는 서버 확인 후 반영한다.
- 광고 수익 + 결제 정산액 − 서버·운영·유입비로 손익을 본다. 광고 제거 이용자의 노출을 빼서 계산한다. 현재 매출 예측값은 없다.
- **서버 무료 운영이 필수다.** 이전 Cloud Run·월 3만원 계획은 폐기했다. Workers/D1 Free 한도 안에서 운영하고 유료 전환은 하지 않는다. 한도 소진 시 신규 구매를 막고 기존 검증 권한·오프라인 플레이를 유지한다. 광고/결제 플랫폼 수수료는 별개다.
- Workers는 일 10만 요청·요청당 CPU 10ms, D1은 일 500만 행 읽기·10만 행 쓰기·총 5GB 무료 한도를 기준으로 설계한다. 한도가 있어 무제한 무료 운영을 약속하지 않는다. [공식 근거](SOURCES.md)
- 초기 유료 유입은 보류. 실제 판 길이·재도전·D1/D7 재방문·광고 노출/이탈·구매 전환·환불을 보고 광고 빈도와 가격을 조정한다.

## 역할과 기록

총괄이 범위·수익·일정·출시 결정을 관리하고, 기획은 시장/정책/권리, 클라이언트는 게임/UI/SDK, 데이터·서버는 Excel/구매 검증, QA는 결함/출시 검증을 맡는다. 각 작업 결과를 이 요약에 반영하며 결정 변경은 [CHANGES.md](CHANGES.md)에 남긴다. 계획·구현·검증·출시를 구분한다.
