미리 보고 놓기열 선택 후 아래 빈칸을 확인하고 놓습니다. 원형 놓기와 무료 되돌리기를 사용합니다. 다시하기·로비는 확인창을 거치고 승리하면 다음 단계로 이어집니다.

신규 첫 실행은 자동 1단계. 제목은 토스 예약 영역 바로 아래, 판과 칸은 정사각형입니다. 짧은 화면은 세로로 스크롤하며 내 차례는 잠깐 팝업으로 알립니다.

확정 계약 v9 · 검증 상태
크림/청록 시안은 사용자 불수용으로 보존만 합니다. v9 Unity 최종 73/73, Excel 44개 검사 통과. 요청 확인 시 이미 시작된 웹 빌드는 완료된 상태였습니다. 브라우저 새 실행은 하지 않았으며 이후 재빌드/실행은 사용자 승인 전 보류합니다.
