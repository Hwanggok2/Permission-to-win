게임과 시장 전략

짧은 규칙과 전술 국면으로 시작합니다. 빈 판 대전만으로 차별화하기 어려워 위협 발견 → 패배 이유 이해 → 즉시 재도전에 집중합니다.

스테이지 선택→AI 대국→결과 · 재도전

4목을 고른 이유: 알까기 물리 튜닝 부담이 없고, 최대 7열 후보로 AI 범위를 줄이기 쉽습니다. 흥행은 아직 검증 전입니다.

재미부터 확인

5명, 각 3판 이상 관찰합니다. 30초 안에 첫 수를 두는지, 패배 이유를 이해하는지, 시키지 않아도 다시 하는지 확인합니다.

초기 판단 목표: 5명 중 3명 자발적 추가 플레이 · 본편 45~120초.
출시 후: D1/D7 재방문, 광고 직후 이탈, 구매 전환·환불.

초기 유입은 스토어·토스 노출 중심. 유지율과 순수익을 확인하기 전 유료 유입 확대는 보류합니다.

노출 간격은 제품 시험값이며 플랫폼 의무값이 아닙니다.

추가된 MVP 범위

광고 제거 1회 구매

3,900원 초기 가격안 · 콘솔 가격 확인 전

전면·배너·리워드 영상을 모두 제거.
힌트는 광고 없이 한 판에 1회 제공합니다.

같은 플랫폼 계정에서 구매 복구. 플랫폼 간 구매 공유는 제외합니다. UI에는 플랫폼에서 조회한 실제 가격을 표시합니다.

원스토어 첫 버전무료 게임 검증과 등급 증빙 확보. 무광고 버전에서는 광고 제거 상품을 판매하지 않습니다. Android 광고망 지원 확인 후 수익화 여부를 결정합니다.
앱인토스 수익화 버전공식 광고 + 공식 IAP를 목표로 합니다. 영구 권리·복구 지원과 SDK 조건을 확인하고 실제 테스트를 마쳐야 판매합니다.
관리할 손익 = 광고 정산액 + 결제 정산액 − 서버·운영·유입비 · 광고 제거 이용자의 노출은 제외, 세금·수수료 중복 공제 주의

서버는 구매 관리에 집중

선택: Cloud Run + Firestore + Secret ManagerNode.js/TypeScript로 플랫폼 주문을 확인하고 권리를 저장합니다. 별도 게임 서버·회원가입·랭킹·진행 동기화는 MVP에서 제외합니다.
복구와 비용 관리통신 실패만으로 기존 구매 권리를 회수하지 않습니다. 환불은 확인 후 반영합니다. 최소 인스턴스 0과 비용 알림을 계획합니다.

클라우드 월 3만원은 초기 관리 목표이며 견적·자동 과금 상한이 아닙니다. 아직 서버를 배포하거나 유료 서비스를 활성화하지 않았습니다. 기술 결정
