# 서버와 사용성 점검

v9 독립 소스 QA 40묶음·0실패를 확인했다. 화면 파괴 뒤 지연 광고 콜백 QA-014 재현과 확인창/차례 팝업/첫 서사 대사 회귀를 포함한다. 결과 JSON은 `Docs/QA/Evidence/qa-rank-v9-runtime-v1-20261014/results.json`에 있다. 실행 후 제품 코드와 데이터는 같으며 관리 계약의 승인 문단만 변경됐다.

**최신 검증/승인 상태:** v9 소스와 프리팹이 동결됐고 최종 Unity 73/73, Excel 44개 검사를 통과했다. 새 브라우저 시험은 미실행이며, 이번 웹 빌드에 사용자 승인이 필요하다는 지시를 받아 이후 재빌드·새 결과 실행을 보류했다. 확인 당시 이미 진행된 WebGL 파일 갱신은 완료 상태였음을 별도로 기록했다. [최종 Unity 화면](assets/v9-match-390.png) · [실행 시각과 상태](../Client/IMPLEMENTATION.md). 아래 제작 중/실패 기록은 그 이전 검사 이력이며 독립 QA의 최신 판정은 연결된 결과 문서를 따른다.

**현재 v9 제작 중:** 흑백 계급 UI의 Unity 67/67 이후 정사각형 판·상단 정렬·모자 얼굴·차례 팝업·원형 놓기·로비/다시하기 확인창을 반영 중이다. 입대한 4목 프로 설정과 지정 첫 대사도 Excel에 연결한다. 아래 이전 검사와 v8 결과를 v9 통과로 사용하지 않는다. [계약 v9](../Docs/Management/CONTRACT.md)을 따르며 사용자 요청에 따라 브라우저만 시험한다.

v8 독립 실행은 중복 제외 25묶음 중 24통과·1실패다. 화면 파괴 후 늦은 광고 완료 콜백이 저장 기록을 바꾸는 QA-014를 재현해 수정·재시험 대상으로 전달했다. [현재 QA](../Docs/QA/RANK-UI-RESULTS.md). 이하 표는 이전 개발판의 검증 이력이다.

2026-10-14. 무료 서버 계획과 Excel 다국어에 이어 토스 상단 영역 분리, 자체 그래픽, 작은 라이선스 메뉴를 개발판에 반영했다. 실제 토스 SDK·기기 검증은 남아 있다.

참고 화면을 바탕으로 챕터별 10개 단계 선택·완료/도전/잠금 표시·그림 도움말·결과 버튼 강조를 구현했다. 완료 정보를 호환 추가해 옛 30단계 해금과 실제 완주를 구분한다. 참고 게임 이미지는 복사하지 않고 기존 자체 도형을 재사용했다. [참고 UX 분석](../Docs/Design/REFERENCE-UX.md).

Unity 전체57/57, 독립 저장8묶음·화면/광고/언어26묶음, 프리팹 참조 검사를 통과했다. 브라우저390↔320 한영·챕터·잠금 차단·그림 도움말·승리 후 다음·패배 후 재도전·복원을 확인했다. 320 최소 조건의 단계 노드 약51px·상태 글자 약12px다. 패배 팝업 뒤의 보드를 보라는 문구는 실제 검사에서 발견해 Excel 3개 문구를 줄였다. 문구 수정 후 영향11개 검사와 최종 두 빌드·브라우저 패배 재시험을 통과했다. 57개와11개는 별도 실행이다. UI는 한 화면의 핵심 행동을 강조하고, 필요한 상태·실패·저장 안내만 남긴다. 라이선스 원문은 별도 메뉴에서 읽는다. 단순한 도형과 색 외 돌 표식을 유지한다. 사람 관찰에서 이해도·재도전·버튼 실수를 확인하기 전 사용자 친화성이나 재미를 완료로 판정하지 않는다.

상단 64px는 공식 토스 버튼 높이가 아닌 자체 안전 여백이다. 세로 320×568, 위59·아래34·좌우0 inset 조건에서 일반 버튼 약47px·보드 열 약44px를 검사했다. 그보다 좁은 가용 영역까지 보장하지 않는다. 설정의 라이선스 진입 글자는 작게 유지하고 전문은 약12.8px 이상으로 확대했다. [최신 화면·브라우저 증거](../Docs/Management/Evidence/host-ui-browser-20261014/README.md) · [독립 QA](../Docs/QA/HOST-UI-RESULTS.md) · [호스트 공식 근거와 한계](../Docs/Design/HOST-UI.md)

언어 데이터는 `Strings`의 `SearchKey / Content_Kor / Content_Eng`에서 관리한다. 런타임은 Excel에서 생성한 JSON을 읽는다. 누락 번역·중복 키·양 언어의 `{0}` 같은 인자 일치를 검사하며, 잘못된 저장 언어는 한국어로 복구한다.

구조는 규모에 맞게 단순하게 유지한다. 규칙·AI와 화면을 분리하고 플랫폼 광고는 인터페이스 뒤에 둔다. 배열은 작은 고정 보드에, Dictionary는 문자열 키 조회에 사용한다. 30개 스테이지는 배열 인덱스로 접근한다. 패턴 수를 늘리는 대신 변경 영향과 실제 기기 측정 결과를 기준으로 개선한다.

서버 무료와 플랫폼 수수료는 별개다. Workers 무료 한도는 일 10만 요청·요청당 CPU 10ms, D1은 일 500만 행 읽기·10만 행 쓰기·총 5GB다. 무제한 무료 운영을 약속하지 않고, 무료 한도 내 서비스와 장애 동작을 검증한다. [공식 근거](SOURCES.md)
