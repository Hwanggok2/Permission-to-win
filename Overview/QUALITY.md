# 서버와 사용성 점검

2026-10-14. 무료 서버 계획과 Excel 다국어에 이어 토스 상단 영역 분리, 자체 그래픽, 작은 라이선스 메뉴를 개발판에 반영했다. 실제 토스 SDK·기기 검증은 남아 있다.

| 항목 | 확인과 조치 | 상태 |
| --- | --- | --- |

UI는 한 화면의 핵심 행동을 강조하고, 필요한 상태·실패·저장 안내만 남긴다. 라이선스 원문은 별도 메뉴에서 읽는다. 단순한 도형과 색 외 돌 표식을 유지한다. 사람 관찰에서 이해도·재도전·버튼 실수를 확인하기 전 사용자 친화성이나 재미를 완료로 판정하지 않는다.

상단 64px는 공식 토스 버튼 높이가 아닌 자체 안전 여백이다. 세로 320×568, 위59·아래34·좌우0 inset 조건에서 일반 버튼 약47px·보드 열 약44px를 검사했다. 그보다 좁은 가용 영역까지 보장하지 않는다. 설정의 라이선스 진입 글자는 작게 유지하고 전문은 약12.8px 이상으로 확대했다. [최신 화면·브라우저 증거](../Docs/Management/Evidence/host-ui-browser-20261014/README.md) · [독립 QA](../Docs/QA/HOST-UI-RESULTS.md) · [호스트 공식 근거와 한계](../Docs/Design/HOST-UI.md)

언어 데이터는 `Strings`의 `SearchKey / Content_Kor / Content_Eng`에서 관리한다. 런타임은 Excel에서 생성한 JSON을 읽는다. 누락 번역·중복 키·양 언어의 `{0}` 같은 인자 일치를 검사하며, 잘못된 저장 언어는 한국어로 복구한다.

구조는 규모에 맞게 단순하게 유지한다. 규칙·AI와 화면을 분리하고 플랫폼 광고는 인터페이스 뒤에 둔다. 배열은 작은 고정 보드에, Dictionary는 문자열 키 조회에 사용한다. 30개 스테이지는 배열 인덱스로 접근한다. 패턴 수를 늘리는 대신 변경 영향과 실제 기기 측정 결과를 기준으로 개선한다.

서버 무료와 플랫폼 수수료는 별개다. Workers 무료 한도는 일 10만 요청·요청당 CPU 10ms, D1은 일 500만 행 읽기·10만 행 쓰기·총 5GB다. 무제한 무료 운영을 약속하지 않고, 무료 한도 내 서비스와 장애 동작을 검증한다. [공식 근거](SOURCES.md)
