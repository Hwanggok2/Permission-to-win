# 서버와 사용성 점검

2026-10-14. 기존 개발판을 실제 코드·Excel·캡처와 대조했다. 기본 구조는 갖췄지만 무료 서버 조건과 완전한 언어 전환은 보완이 필요했다.

| 항목 | 확인과 조치 | 상태 |
| --- | --- | --- |
| 무료 서버 | Cloud Run은 무료 사용량 초과 과금이 가능해 기존 선택을 폐기. Workers Free + D1 Free로 계획 변경, 한도 소진 시 신규 구매 중지·기존 권한/플레이 유지 | 무료 플랜·토스 인증서·실연동 검증 전 |
| 광고와 결제 | 광고는 플랫폼 SDK, 구매는 플랫폼 IAP와 서버 검증을 연결. 서버 업체 선택만으로 SDK 연동이 완료되지는 않음 | 실제 SDK/IAP 미연결 |
| UI와 그래픽 | 짙은 배경·민트/산호 돌·공통 버튼/닫기 프리팹 유지. 개발 문구·빈 배너 제거, 닫기 영역·긴 영어 제목·크기 변경 축소 보완 | Unity 42테스트·브라우저 390↔320 화면/입력 확인 |
| 문구와 다국어 | 기존 한국어 전용 58개를 보존하고 UI용 문구를 추가해 한영 123개 구성. Excel 열·키 참조·설정 전환·저장 복원 구현 | 데이터 36테스트·독립 코어 29묶음 통과, 브라우저 전환·복원 확인 |
| 코드 구조 | 순수 C# 규칙/AI, 플랫폼 광고 인터페이스, 로컬 저장, 저장된 UI 참조로 역할 분리 | 확인 |
| 자료구조/성능 | 보드 42칸/열 높이 7칸 배열, 문자열 Dictionary, 반복 심화·알파베타·탐색 시간 제한 사용. AI 자식별 복제/할당은 실기기 프로파일 후 개선 여부 판단 | 구조 확인, 실기기 최적화 미검증 |

UI는 한 화면의 핵심 행동을 강조하고, 필요한 상태·실패·저장 안내만 남긴다. 라이선스 원문은 별도 메뉴에서 읽는다. 단순한 도형과 색 외 돌 표식을 유지한다. 사람 관찰에서 이해도·재도전·버튼 실수를 확인하기 전 사용자 친화성이나 재미를 완료로 판정하지 않는다.

언어 데이터는 `Strings`의 `SearchKey / Content_Kor / Content_Eng`에서 관리한다. 런타임은 Excel에서 생성한 JSON을 읽는다. 누락 번역·중복 키·양 언어의 `{0}` 같은 인자 일치를 검사하며, 잘못된 저장 언어는 한국어로 복구한다.

구조는 규모에 맞게 단순하게 유지한다. 규칙·AI와 화면을 분리하고 플랫폼 광고는 인터페이스 뒤에 둔다. 배열은 작은 고정 보드에, Dictionary는 문자열 키 조회에 사용한다. 30개 스테이지는 배열 인덱스로 접근한다. 패턴 수를 늘리는 대신 변경 영향과 실제 기기 측정 결과를 기준으로 개선한다.

서버 무료와 플랫폼 수수료는 별개다. Workers 무료 한도는 일 10만 요청·요청당 CPU 10ms, D1은 일 500만 행 읽기·10만 행 쓰기·총 5GB다. 무제한 무료 운영을 약속하지 않고, 무료 한도 내 서비스와 장애 동작을 검증한다. [공식 근거](SOURCES.md)
