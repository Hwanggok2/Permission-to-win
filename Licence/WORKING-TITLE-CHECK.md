# 작업명 예비 확인 — 한 수 진급 / Rank by Rank

확인일: **2026-10-14 (Asia/Seoul)**. 상태: **내부 작업명, 권리 미확정**. 상표 사용 가능·등록 가능·동일/유사 상표 없음·권리 확보를 판정하지 않았다. 현재 UI 시안의 표시명이며 공개 출시명 확정으로 취급하지 않는다.

| 실행 범위 | 확인 결과와 한계 |
| --- | --- |
| 공식 서비스 확인 | [KIPRIS](https://www.kipris.or.kr/)와 [공식 검색 안내](https://www.kipris.or.kr/khome/board/help/introduce.do), [WIPO Global Brand Database 안내](https://www.wipo.int/en/web/global-brand-database) 및 연결된 [검색 서비스](https://branddb.wipo.int/)를 열었다. 이 웹 도구에서는 KIPRIS/BrandDB의 동적 상표 검색 결과 목록을 읽을 수 없었다. |
| 공식 도메인 한정 웹 색인 검색 | `한 수 진급`, `한수진급`, `랭크 바이 랭크`를 kipris.or.kr에, `Rank by Rank`를 kipris.or.kr/wipo.int에 한정해 정확 구문으로 조회했다. 해당 질의의 웹 검색 결과가 반환되지 않았다. 이는 공식 DB 내부 상표 검색의0건 결과가 아니다. |
| 미실시 | 공식 DB의 유사 호칭·표기·의미, 지정상품/서비스, 출원·등록 상태와 권리자에 대한 개별 기록 대조. 해외 전 지역, 게임명·상호·도메인 등 다른 권리 검토도 수행하지 않았다. |

후속 출시명 검토에서는 KIPRIS의 실제 상표 결과 화면에서 한글 띄어쓰기/붙임·영문·유사 발음을 조사하고, 관련 지정상품/서비스와 개별 건의 상태를 함께 기록한다. WIPO도 자체 DB 외 각 국가/지역 상표부의 추가 검색이 필요할 수 있다고 안내한다. [WIPO 검색 범위 안내](https://www.wipo.int/en/web/global-brand-database)

이번 UI용 흰 바탕·검정 격자·흑백 돌·단순 얼굴은 자체 도형 제작 계획이며 새 외부 폰트·이미지 도입을 승인한 것이 아니다. 참고 PNG의 이용 허가나 실제 군 문장/계급장 사용 권한을 이름 검색으로 대신하지 않는다.
