# 광고 빈도·구매 안내 데이터 변경

확인일: 2026-10-18. 상태: Excel 원본·JSON 생성·데이터 자동 검증 완료. Client 복사·런타임 광고/구매 동작·실광고 및 스토어 검증은 이 기록에 포함하지 않는다.

## 반영 내용

- `AdConfig!B5:D5`: 최초 제외 판수 `3→0`, 완료판 간격 `2→1`, 시간 간격(초) `90→0`. 다른 광고 필드는 유지했다.
- 스토리 정상 완료 매판이 대상이다. 멀티는 정상 대국 이후 방 나가기→로비 경계에서 최대 1회가 대상이며, 방 안의 리매치마다 광고를 띄우는 규칙이 아니다. 이 경계·누적·중복 방지는 런타임에서 판정한다.
- 6판/180초 제안은 채택하지 않았다. JSON schemaVersion 1은 유지한다.
- `Strings!A495:E506`: 광고 제거 구매 안내 `ad_offer_*` 12개. 기존 490개를 보존하여 총 502개다. 닫기는 `ui_close`를 재사용하고, 구매 취소는 별도 오류 문구 없이 돌아온다. 구매 버튼의 `{0}`은 플랫폼 표시 가격을 받는다.
