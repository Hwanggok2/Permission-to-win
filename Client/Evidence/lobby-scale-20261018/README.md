# 광고 제거 패널·상단 아이콘 크기 수정 — 2026-10-18

사용자가 보고한 패널 축소와 상단 아이콘 과대 표시를 수정했다. 저장 프리팹 적용·Unity 검증·웹 빌드·로컬 브라우저 확인 완료. **Pages 커밋 `4a09d8c`는 사용자 푸시 대기**다. 이번 작업에서 원격 푸시는 하지 않았다.

## 변경

- 패널의 `350 CSS px` 너비 상한을 제거했다. 게임의 세로 SafeArea 내용 폭 92%를 사용하고 바깥 닫기 여백은 최소 12 CSS px 남긴다. 1080×1920/DPR1에서 기존 350px(32.4%) 대신 993.6px(92%)가 된다.
- 글자·행·버튼·닫기·복원 슬롯을 함께 확대한다. 작은 화면은 최소 터치 크기를 유지하고, 짧은 호스트 영역은 보조 문구와 간격을 줄여 전체 내용을 표시한다.
- 도움말/광고 제거/설정 아이콘의 그림 Rect를 720 기준 각각 90→64, 104→56, 72→46으로 축소했다. 배경 없는 표현과 110×110 입력 영역은 유지하고 밝은 외곽선을 그림 크기에 맞췄다.
- 변경은 기존 저장 Lobby 프리팹과 배치 코드에 적용했다. 신규 자산·문구·SDK·서버 변경 없음.
