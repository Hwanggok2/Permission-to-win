# 멀티 음악·착수 반응·승패 연출 — 2026-10-19

멀티 화면에서 빠져 있던 BGM 재생 조건을 복구하고, 서버 응답을 기다리던 내 착수 표시를 즉시 표시하도록 변경했다. 마지막 수 확대·축소, 큰 승패 안내, 레이팅 변화와 하단 두 행동을 저장 프리팹에 적용했다. 서버 규칙·점수 공식·광고 조건은 유지한다.

## 동작

- 멀티 메뉴·대국·결과·리매치에서도 같은 음악을 이어서 재생한다. 음악 설정과 포커스/광고 일시정지는 유지한다.
- 놓기를 누르면 같은 입력 프레임에 예상 돌과 효과음을 표시한다. 서버 보드·seq·승패·점수는 수정하지 않는다. 승인 시 중복 효과음을 내지 않으며 거절·끊김에는 예상 표시를 되돌린다. 5초 무응답은 재접속으로 복구하고 착수 명령을 재전송하지 않는다.
- 정상 종료의 실제 마지막 돌을 1→1.65→1배로 0.65초 확대·축소한다. 금색 테두리와 승리 연결선을 표시한다. 이어서 서버 확정 레이팅까지 0.55초 동안 숫자를 변화시킨다.
- 상단에 승리/패배/무승부/경기 무효를 크게 표시한다. 하단의 점수, 상대 알림, 다시하기/나가기를 분리하고 두 버튼을 같은 줄에 고정한다. 연출 중에도 두 행동을 사용할 수 있다.
- 재접속으로 받은 이미 종료된 경기는 정적인 최종 결과만 표시한다. 리매치·퇴장·비활성화에는 이전 확대와 숫자 연출을 취소한다. 시간패·포기에는 가짜 마지막 돌 확대를 추가하지 않는다.
- 사용자 문구 7개는 Excel Strings 한영 열에서 생성했다. [데이터 검증](../../../GameData/Validation/multiplayer-feedback-20261019/README.md).
