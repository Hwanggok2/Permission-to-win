# 앱 실행별 착수 안내와 대국 도움말 — 2026-10-16

## 구현

- 정상적인 열 선택 때 하단의 “N번 열 선택됨. 놓기를 눌러 확정하세요.”를 제거한다. 돌 미리보기와 놓기 버튼은 유지한다. 가득 찬 열 등 오류/상황 안내는 유지한다.
- 중앙의 흰색 착수 안내는 앱 실행 후 첫 대국에서 플레이어의 첫 턴에만 3초 표시한다. 열을 고르면 즉시 숨긴다. 다시하기, 되돌리기, 다음 스테이지, 로비 왕복, 언어 변경, 도움말 닫기, 백그라운드 복귀, 씬 재로드에서는 반복하지 않는다.
- 세션 상태는 진행 저장과 분리한다. Unity SubsystemRegistration에서만 초기화해 앱/Play 재시작 때 다시 표시한다. AI 선공이면 첫 사람 턴까지 기다리며, 첫 판에서 나간 경우 다음 판으로 안내를 넘기지 않는다.
- 최초 설치 실행의 규칙 패널은 기존대로 한 번 자동 표시하고, 닫은 후 중앙 안내를 표시한다.
- 대국 좌측 상단에 기존 도움말 아이콘을 사용한 `?` 버튼을 저장했다. 우측 일시정지 버튼의 Y, 크기, 반대편 X를 그대로 따른다. 정사각형 배경 96×96, 터치 영역 165×156 설계 단위. Match/RankAppRoot 프리팹에 저장된 참조와 클릭 효과음 배열로 연결한다.
- 버튼은 기존 규칙 패널을 다시 연다. 패널이 열린 동안 착수·AI·대사·제한 시간은 멈추며 BGM은 이어진다. 닫으면 선택한 열과 남은 시간을 유지한다. 결과 화면에서는 버튼을 숨긴다.
