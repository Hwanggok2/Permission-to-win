## 적용 내용

- X 외곽선을 제거하고 44 CSS px 입력 영역 및 배경색 포커스 표시를 유지했다. X/바깥 터치/보조 닫기/Escape는 즉시 닫으며 내부 빈 곳은 닫히지 않는다.
- Excel Strings의 한국어 설명은 **구매하면 전면·배너 광고가 영구적으로 사라집니다**이며 대응 영어도 적용했다. 총502키, 기존490키 보존 확인. 가격은 어댑터의 상품 표시 가격이며 테스트 캡처의 ₩3,900은 예시다.
- 이전 실행에서 스토리 또는 멀티 대국을 마친 이용자에게 새 실행의 안전한 로비에서 최대1회 홍보 기회를 검사한다. 첫 안내·초대·다른 화면 이동이 우선이며 뒤늦게 홍보를 끼워 넣지 않는다. 새 WebGL 인스턴스는 새 실행, 동일 인스턴스의 로비 재방문/백그라운드 복귀는 같은 실행이다.
- 상품 준비·표시 가격·검증된 권리 확인 완료·미보유·광고 연결이 모두 필요하다. 구매 콜백만으로 권리를 지급하지 않는다. 검증된 보유자는 광고를 제외하고 싱글 힌트를 판당1회 사용한다.
- 스토리는 정상 승리·패배·무승부마다 완료 ID당 전면광고 기회 최대1회. Excel 광고 설정은 유예0/주기1/간격0이며 중도 포기·재시작은 제외한다.
- 멀티는 현재 판의 정상 `four`/`draw` 종료 후 나가기를 눌러 서버 퇴장이 확인된 로비 복귀에서 최대1회. 리매치 중·검색/친구 대기·포기·시간패·연결 중단·무효 결과·퇴장 확인 실패는 제외한다. 리매치 판수를 누적 노출하지 않고 새 판/방/idle에서 이전 완료 자격을 지운다.
- 광고 실패/미충전/예외/취소/기한 초과에는 진행을 복구한다. 화면 이동·백그라운드·검증된 구매 이후 늦은 콜백과 중복 응답은 무효화한다.
