# 광고 제거 홍보 시안 브라우저 검증

2026-10-18 KST. 독립 HTML 시안 검증이며 실제 Unity 패널·IAP·실광고를 구현하거나 공개 배포한 기록이 아니다. 수정 전 시안의 역사적 기록이다. 이후 사용자 수정 승인과 실제 저장 프리팹 구현 결과는 [후속 기록](../ad-offer-implementation-20261018/README.md)을 따른다.

- [시안](../../../Docs/Design/ad-removal-ui-20261018/index.html) · [설계](../../../Docs/Design/ad-removal-ui-20261018/design-spec.md) · [독립 검토](../../../Docs/QA/AD-REMOVAL-UI-REVIEW-20261018.md)
- IAB에서 한영 각각 360×640, 390×844, 320×568, 320×403 CSS px를 렌더링하고 8개 PNG를 저장했다. 360×640은 1080×1920과 같은 화면 비율을 점검한 것이며 실제 DPR 3 기기를 검사했다는 뜻은 아니다.
- `layout-measurements.json`: 8개 모두 카드 내부 세로 넘침 없음. X 44px, 구매 48~52px, 보조 닫기·복원 44px 높이이며 모든 행동이 가용 화면 안에 있다.
- `interactions.json`: X/바깥/보조 닫기/Escape/브라우저 뒤로 닫기, 카드 내용 터치 시 유지, Tab 포커스 순환, 구매·복원 예시 안내의 9가지 실제 브라우저 확인을 통과했다. 구매와 복원은 예시이며 결제·권리 조회를 하지 않았다.
- `state-checks.json`: 10개 상태 중 이전 실행에서 대국을 마친 정상 재방문만 노출. 첫 실행, 이전 대국 미완료, 구매자, 권리 확인 중, 상품 조회 실패, 현재 Pages, 초대, 재접속/대기, 처음 안내는 미노출이었다.
- 총괄은 브라우저 실행을, 별도 리뷰 세션은 소스와 저장된 캡처의 독립 시각 검토를 담당했다. 실제 폰 터치·스크린리더·실제 결제·광고 SDK 검증은 수행하지 않았다.

예시 가격 3,900원은 운영 상품 조회 가격을 대신하지 않는다. 당시 노출 조건과 최초 6번째 정상 대국 이후·추가 3판 및 180초 광고안은 승인 전 제안이었다. 사용자는 후속 답변에서 스토리 매판·멀티 로비 복귀만으로 확정했으며 6판/180초 안은 채택되지 않았다.
