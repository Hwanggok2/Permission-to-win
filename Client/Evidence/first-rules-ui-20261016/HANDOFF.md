# 최초 규칙 안내·중앙 착수 안내·작은 버튼 — 2026-10-16

Client 소스와 실제 프리팹 반영 완료. Unity 배치 종료 및 프로젝트 잠금 해제 확인. `source-freeze.json`의 Client Assets/Packages/ProjectSettings와 원본 Excel/Generated 해시를 기준으로 총괄이 후속 빌드할 수 있다. 이번 작업에서 새 WebGL/Android 플레이어 빌드·배포·커밋·푸시는 하지 않았다.

- **최초 실행에 한 번:** 사용자가 선택한 주기다. 기존 진행 저장이 없는 첫 실행에서 첫 대국 위에 저장된 Help 프리팹을 표시한다. 다시 실행하거나 정상/복구 저장이 있으면 기존처럼 로비로 시작한다. 도움말 버튼으로 언제든 다시 볼 수 있다. 기존 사용자 저장을 삭제하거나 별도 저장 형식을 추가하지 않았다.
- **규칙:** 아래로 쌓이는 그림과 함께 “돌은 아래에서부터 쌓여요”, “네 개를 연결하면 승리”, 가로·세로·대각선 그림을 표시한다. Excel Strings `help_drop_title`의 C138/E138만 변경했다. 영문은 `Stones stack from the bottom`. 기존 설명과 30초 자동 착수 설명을 재사용한다. 다른 값/서식/시트 기능 보존 및 Generated/Resources 동기화를 확인했다.
- **패널이 열린 동안:** 타이머·대사 타이핑·착수·되돌리기·AI 진행은 멈추고 BGM은 계속된다. 일시정지/다시하기/힌트도 비활성 및 직접 호출 차단한다. 닫으면 같은 남은 시간으로 계속하며 중앙 안내를 보여준다.
- **중앙 착수 안내:** 기존 `select_column` 문자열을 화면 중앙에 흰색 굵은 글자와 짙은 외곽선으로 표시한다. 2.6초 유지 후 0.4초 사라지며, 열을 선택하면 즉시 사라진다. 재시작과 내 턴에도 표시한다. 기존 짧은 내 차례 텍스트 토스트를 이 안내로 바꿨으며 하단의 같은 안내는 숨긴다. 열 선택 확인·실패·시간 초과 등 다른 문맥 안내는 기존 위치를 유지한다. 안내에는 레이캐스트 차단이 없다.
- **되돌리기/다시하기:** 배경만 336×165 → **255×114 설계 단위**로 축소했다(가로24.1%, 세로30.9%). 전체 터치 영역336×165는 유지한다. 배경에 버튼 상태 색상이 적용되며 투명한 가장자리도 기존 버튼으로 클릭된다. 놓기 버튼·결과 화면 버튼·보드·캐릭터·헤더 배치는 유지했다.

## 저장 및 검증

`RankUiBuilder.ApplyFirstRulesAndCompactControls`가 Match/TurnToast/RankAppRoot 프리팹을 저장한다. 전체 Rank UI와 Pixel UI 제작 경로에도 같은 설정을 연결했다. 런타임에 UI 트리를 만들지 않는다. 원본 아트/오디오/메타·Core AI 코드·스테이지/광고 데이터·씬·다른 프리팹의 해시는 작업 전과 같다.

- Unity **16/16** 통과, 최종 모달 입력 차단 보강 후 영향 항목 **4/4 재실행 통과**. 총 고유 항목은16개이며 재실행을 중복 합산하지 않는다.
- 데이터 검사 **46/46**, exporter `--check`, Generated/Resources JSON 일치.
- 최초 규칙 패널의 한영 표시, 새 실행의 타이머/착수 차단 및 음악 유지, 닫기 후 재개, 재실행에서 반복되지 않음, 도움말 재호출을 검사했다.
- 1080×1920 / 390×664 / 390×844 / 454×768에서 한영 규칙 패널·중앙 안내·작은 버튼을 캡처했다. 흰 안내의 중앙 좌표, 하단 버튼 잘림 없음, 투명한 버튼 가장자리 레이캐스트를 검사했다. 기존 DPR1/1.5/2 모바일/호스트 회귀도 통과했다.
- 결과/제한: Unity RenderTexture 캡처와 Play 자동 검사다. 새 WebGL 빌드, 실제 아이폰/Android, 사람 플레이 검사는 하지 않았다. 진행 저장이 이미 있는 사용자에게 첫 실행 패널이 다시 뜨지 않는 것은 의도된 동작이다.
