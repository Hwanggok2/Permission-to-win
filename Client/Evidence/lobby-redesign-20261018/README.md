## 변경

- 하단은 전체 폭 멀티 배틀 버튼 하나다. 흑백 돌 문양·행동명·오른쪽 내 레이팅을 분리했다.
- 광고 제거는 도움말 옆의 글자 없는 PNG 아이콘으로 옮겼다. 도움말·설정·광고 제거는 투명한 110×110 기준 입력 영역만 남기고 큰 버튼 바탕을 없앴다. 물음표와 톱니는 확대하고 밝은 도트 외곽선으로 대비를 확보했다.
- 스테이지 카드는 군부대 임무 카드 느낌의 번호 띠·종이색 면·테두리·강조선·난이도/레이팅 구획을 적용했다. 현재 화살표·완료 체크·잠금 표식을 밝게 표시한다. 2열 스크롤과 한영 문구는 유지한다.
- 실제 본인 서버 점수는 대전과 별개인 프로필 조회로 읽는다. 초대 상대의 점수를 사용하지 않는다. 신규 200점, 미확인 기존 계정 `—`, 결과 후 갱신·퇴장 후 유지·식별자 변경/401 초기화·일시 네트워크 실패 시 마지막 확인값 유지.
- 모든 UI는 저장 프리팹과 직렬화 참조로 구성했다. 새 문구는 추가하지 않고 기존 Excel Strings를 재사용했다.
